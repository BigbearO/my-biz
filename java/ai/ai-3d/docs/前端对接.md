# 诊前助手 UniApp 前端对接文档

## 一、接口概览

| 接口 | 方法 | 路径 | 说明 |
|---|---|---|---|
| 诊前对话 | POST | `/api/v2/chat` | SSE 流式返回，含文字+选项+音频 |
| TTS 降级 | GET | `/api/v2/tts?text=xxx` | 返回 MP3 字节，App/小程序降级用 |

---

## 二、SSE 事件协议

### 请求

```
POST /api/v2/chat
Content-Type: application/json

{
  "message": "我最近头痛",
  "conversationId": "conv_123456"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| message | string | 是 | 用户输入的消息，或点击选项的 value |
| conversationId | string | 是 | 会话唯一标识，同一会话保持一致 |

### 响应

`Content-Type: text/event-stream`

每条 SSE 事件的 `data` 字段为 JSON，通过 `type` 区分事件类型：

#### 2.1 thinking — 思考中

当 AI 进入思考阶段时推送，前端应展示"思考中"动画（如跳动圆点）。

```json
{"type":"thinking"}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定值 `"thinking"` |

> 收到 `chunk` 事件后应自动关闭思考动画。同一轮对话中 `thinking` 只会出现一次。

#### 2.2 chunk — 文本流式片段

逐字推送，前端应追加渲染到当前助手消息气泡。

```json
{"type":"chunk","content":"您好！"}
{"type":"chunk","content":"请问哪里不舒服？"}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定值 `"chunk"` |
| content | string | 本次推送的文本片段 |

#### 2.3 options — 可选项

流式文本结束后推送，前端渲染为按钮组。

```json
{
  "type": "options",
  "items": [
    {"label": "头痛", "value": "我最近头痛"},
    {"label": "咳嗽", "value": "我最近咳嗽"},
    {"label": "肚子疼", "value": "我肚子疼"},
    {"label": "其他症状", "value": "我有其他不舒服"}
  ]
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定值 `"options"` |
| items | array | 选项列表 |
| items[].label | string | 按钮显示文本 |
| items[].value | string | 点击后发送的消息内容 |

#### 2.4 phase — 当前问诊阶段

```json
{"type":"phase","value":"CHIEF_COMPLAINT"}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定值 `"phase"` |
| value | string | 阶段标识 |

阶段枚举：

| 阶段 | 说明 | 典型轮次 |
|---|---|---|
| GREETING | 开场共情 | 第1轮 |
| CHIEF_COMPLAINT | 聚焦主诉 | 第2-3轮 |
| HPI | 现病史深挖 | 第4-7轮 |
| MEDICAL_HISTORY | 基础健康筛查 | 第8-10轮 |
| GOAL | 明确就诊目标 | 第11-13轮 |
| SUMMARY | 生成摘要 | 第14-15轮 |

#### 2.5 summary — 病情摘要

仅在问诊完成时推送一次。

```json
{
  "type": "summary",
  "content": "【主诉】头痛3天\n【现病史】持续性胀痛，伴恶心\n【既往史】无慢性病\n【用药情况】未服药\n【过敏史】无\n【就诊诉求】明确诊断"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定值 `"summary"` |
| content | string | 病情摘要文本 |

#### 2.6 done — 流结束

```json
{
  "type": "done",
  "completed": false
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定值 `"done"` |
| completed | boolean | 是否已完成问诊（SUMMARY阶段为 true） |

> `audio` 字段已废弃，音频通过独立的 `audio` 事件异步推送。

#### 2.7 audio — TTS 音频

TTS 合成完成后异步推送，前端收到后播放音频。

```json
{
  "type": "audio",
  "audio": "SUQzBAAAAAAAI1RTU0UAAAAPAAADTGF2ZjU4Ljc2LjEwMAAAAAAAAAAAAAAA//tQ..."
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| type | string | 固定值 `"audio"` |
| audio | string | base64 编码的 MP3 音频数据 |

> TTS 是异步合成，`audio` 事件可能在 `done` 事件之后才到达。前端应立即展示文字内容，音频到达后再播放。

#### 2.8 error — 错误

```json
{"type":"error","message":"消息不能为空"}
```

## 三、完整交互时序

```
前端                              后端
 │                                 │
 │  POST /api/v2/chat              │
 │  {message, conversationId}      │
 │────────────────────────────────>│
 │                                 │
 │  SSE: thinking                  │  ← 展示"思考中"动画
 │<────────────────────────────────│
 │  SSE: chunk "您好！"            │  ← 逐字渲染到气泡，关闭思考动画
 │<────────────────────────────────│
 │  SSE: chunk "请问哪里不舒服？"   │
 │<────────────────────────────────│
 │  ...更多 chunk...               │
 │                                 │
 │  SSE: options [{label,value}]   │  ← 渲染选项按钮
 │<────────────────────────────────│
 │  SSE: phase "CHIEF_COMPLAINT"   │  ← 更新阶段指示器
 │<────────────────────────────────│
 │  SSE: done {completed}          │  ← 流结束
 │<────────────────────────────────│
 │  SSE: audio {audio: base64}     │  ← 异步音频到达，播放
 │<────────────────────────────────│
 │                                 │
 │  用户点击选项 "我最近头痛"       │
 │  POST /api/v2/chat              │
 │  {message:"我最近头痛", ...}     │
 │────────────────────────────────>│
 │  ...下一轮...                   │
 │                                 │
 │  (最终轮)                       │
 │  SSE: summary "【主诉】..."      │  ← 展示摘要卡片
 │<────────────────────────────────│
 │  SSE: done {completed:true}     │  ← 问诊完成
 │<────────────────────────────────│
```

## 四、UniApp 代码示例

### 4.1 请求与 SSE 解析

UniApp 不原生支持 `EventSource`，需要使用 `uni.request` 配合分块传输：

```javascript
export default {
  data() {
    return {
      messages: [],          // 消息列表
      conversationId: '',    // 会话ID
      isStreaming: false,    // 是否正在流式输出
      currentPhase: '',      // 当前问诊阶段
      summary: '',           // 病情摘要
      inputText: '',         // 输入框文本
      currentAssistantMsg: null  // 当前正在流式输出的助手消息
    }
  },

  methods: {
    /**
     * 发送消息
     * @param {string} text - 消息内容
     */
    sendMessage(text) {
      if (!text || !text.trim() || this.isStreaming) return

      // 添加用户消息
      this.messages.push({
        role: 'user',
        content: text.trim(),
        options: []
      })

      // 初始化助手消息占位
      this.currentAssistantMsg = {
        role: 'assistant',
        content: '',
        options: [],
        phase: ''
      }
      this.messages.push(this.currentAssistantMsg)
      this.isStreaming = true
      this.inputText = ''

      // 生成会话ID（首次）
      if (!this.conversationId) {
        this.conversationId = 'conv_' + Date.now() + '_' + Math.random().toString(36).substr(2, 9)
      }

      // 发起 SSE 请求
      this.requestSse(text.trim())
    },

    /**
     * SSE 请求
     */
    requestSse(message) {
      const baseUrl = 'http://your-server:9998'  // 替换为实际地址

      // #ifdef H5
      // H5 环境：使用 fetch + ReadableStream
      this.requestSseH5(baseUrl, message)
      // #endif

      // #ifdef APP-PLUS || MP
      // App/小程序环境：使用 uni.request
      this.requestSseApp(baseUrl, message)
      // #endif
    },

    /**
     * H5 环境 SSE（推荐，体验最好）
     */
    async requestSseH5(baseUrl, message) {
      try {
        const response = await fetch(`${baseUrl}/api/v2/chat`, {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({
            message: message,
            conversationId: this.conversationId
          })
        })

        const reader = response.body.getReader()
        const decoder = new TextDecoder()
        let buffer = ''

        while (true) {
          const { done, value } = await reader.read()
          if (done) break

          buffer += decoder.decode(value, { stream: true })

          // 按行解析 SSE
          const lines = buffer.split('\n')
          buffer = lines.pop()  // 保留未完成的行

          for (const line of lines) {
            if (line.startsWith('data:')) {
              const jsonStr = line.substring(5).trim()
              if (jsonStr) {
                this.handleSseEvent(JSON.parse(jsonStr))
              }
            }
          }
        }
      } catch (e) {
        console.error('SSE 请求失败', e)
        this.isStreaming = false
        uni.showToast({ title: '请求失败', icon: 'none' })
      }
    },

    /**
     * App/小程序环境 SSE（降级方案）
     * 注意：uni.request 的 enableChunked 在部分平台支持有限
     * 如不支持，可改用轮询或 WebSocket 方案
     */
    requestSseApp(baseUrl, message) {
      let fullData = ''

      const requestTask = uni.request({
        url: `${baseUrl}/api/v2/chat`,
        method: 'POST',
        header: { 'Content-Type': 'application/json' },
        data: { message, conversationId: this.conversationId },
        responseType: 'text',
        enableChunked: true,
        success: (res) => {
          fullData = res.data || ''
          this.parseFullSseResponse(fullData)
        },
        fail: (err) => {
          console.error('请求失败', err)
          this.isStreaming = false
          uni.showToast({ title: '请求失败', icon: 'none' })
        }
      })
    },

    /**
     * 解析完整 SSE 响应（App/小程序降级用）
     */
    parseFullSseResponse(raw) {
      const lines = raw.split('\n')
      for (const line of lines) {
        if (line.startsWith('data:')) {
          const jsonStr = line.substring(5).trim()
          if (jsonStr) {
            try {
              this.handleSseEvent(JSON.parse(jsonStr))
            } catch (e) {
              console.error('SSE 事件解析失败', jsonStr)
            }
          }
        }
      }
    },

    /**
     * 处理单个 SSE 事件
     */
    handleSseEvent(event) {
      switch (event.type) {
        case 'chunk':
          // 追加文本到当前助手消息
          if (this.currentAssistantMsg) {
            this.currentAssistantMsg.content += event.content
          }
          break

        case 'options':
          // 设置可选项
          if (this.currentAssistantMsg) {
            this.currentAssistantMsg.options = event.items || []
          }
          break

        case 'phase':
          // 更新问诊阶段
          this.currentPhase = event.value
          if (this.currentAssistantMsg) {
            this.currentAssistantMsg.phase = event.value
          }
          break

        case 'summary':
          // 保存病情摘要
          this.summary = event.content
          break

        case 'done':
          // 流结束
          this.isStreaming = false
          this.currentAssistantMsg = null

          // 播放音频
          if (event.audio) {
            this.playAudio(event.audio)
          }

          // 问诊完成
          if (event.completed) {
            uni.showToast({ title: '问诊已完成', icon: 'success' })
          }
          break

        case 'error':
          this.isStreaming = false
          uni.showToast({ title: event.message || '出错了', icon: 'none' })
          break
      }
    },

    /**
     * 点击选项按钮
     */
    onOptionClick(option) {
      // 方式1：直接填入输入框，用户确认后发送
      this.inputText = option.value

      // 方式2：直接发送（取消注释下面这行，注释上面那行）
      // this.sendMessage(option.value)
    },

    /**
     * 播放音频
     */
    playAudio(base64) {
      // #ifdef H5
      this.playAudioH5(base64)
      // #endif

      // #ifdef APP-PLUS
      this.playAudioApp(base64)
      // #endif

      // #ifdef MP
      // 小程序不支持 base64 播放，降级为 TTS 接口
      this.playAudioMp()
      // #endif
    },

    /**
     * H5 播放音频
     */
    playAudioH5(base64) {
      try {
        const binaryStr = atob(base64)
        const bytes = new Uint8Array(binaryStr.length)
        for (let i = 0; i < binaryStr.length; i++) {
          bytes[i] = binaryStr.charCodeAt(i)
        }
        const blob = new Blob([bytes], { type: 'audio/mpeg' })
        const url = URL.createObjectURL(blob)
        const audio = new Audio(url)
        audio.play()
      } catch (e) {
        console.error('H5 音频播放失败', e)
      }
    },

    /**
     * App 端播放音频
     */
    playAudioApp(base64) {
      try {
        // 方式1：保存为临时文件后播放
        const fs = uni.getFileSystemManager()
        const filePath = `${wx.env.USER_DATA_PATH}/tts_${Date.now()}.mp3`
        const buffer = uni.base64ToArrayBuffer(base64)
        fs.writeFile({
          filePath: filePath,
          data: buffer,
          encoding: 'binary',
          success: () => {
            const innerAudio = uni.createInnerAudioContext()
            innerAudio.src = filePath
            innerAudio.onEnded = () => {
              // 清理临时文件
              fs.unlink({ filePath: filePath })
            }
            innerAudio.play()
          },
          fail: (err) => {
            console.error('写入音频文件失败', err)
          }
        })
      } catch (e) {
        console.error('App 音频播放失败', e)
      }
    },

    /**
     * 小程序降级：通过 TTS 接口获取音频
     */
    playAudioMp() {
      // 取最后一条助手消息的文本
      const lastMsg = [...this.messages].reverse().find(m => m.role === 'assistant')
      if (!lastMsg || !lastMsg.content) return

      const baseUrl = 'http://your-server:9998'
      const innerAudio = uni.createInnerAudioContext()
      innerAudio.src = `${baseUrl}/api/v2/tts?text=${encodeURIComponent(lastMsg.content)}`
      innerAudio.play()
    }
  }
}
```

### 4.2 页面模板示例

```html
<template>
  <view class="chat-container">
    <!-- 阶段指示器 -->
    <view class="phase-bar">
      <text class="phase-text">{{ phaseLabel }}</text>
    </view>

    <!-- 消息列表 -->
    <scroll-view class="message-list" scroll-y :scroll-top="scrollTop" :scroll-with-animation="true">
      <view v-for="(msg, index) in messages" :key="index" class="message-item">
        <!-- 用户消息 -->
        <view v-if="msg.role === 'user'" class="msg-user">
          <view class="msg-bubble user-bubble">{{ msg.content }}</view>
        </view>

        <!-- 助手消息 -->
        <view v-else class="msg-assistant">
          <view class="msg-bubble assistant-bubble">
            <text>{{ msg.content }}</text>
            <!-- 加载动画 -->
            <text v-if="isStreaming && msg === currentAssistantMsg" class="cursor">|</text>
          </view>

          <!-- 选项按钮 -->
          <view v-if="msg.options && msg.options.length > 0 && !isStreaming" class="options-container">
            <view
              v-for="(opt, oi) in msg.options"
              :key="oi"
              class="option-btn"
              @tap="onOptionClick(opt)"
            >
              {{ opt.label }}
            </view>
          </view>
        </view>
      </view>
    </scroll-view>

    <!-- 摘要卡片 -->
    <view v-if="summary" class="summary-card">
      <view class="summary-title">病情摘要</view>
      <text class="summary-content">{{ summary }}</text>
    </view>

    <!-- 输入区域 -->
    <view class="input-area">
      <input
        v-model="inputText"
        class="chat-input"
        placeholder="请描述您的症状..."
        :disabled="isStreaming"
        confirm-type="send"
        @confirm="sendMessage(inputText)"
      />
      <button
        class="send-btn"
        :disabled="isStreaming || !inputText.trim()"
        @tap="sendMessage(inputText)"
      >
        发送
      </button>
    </view>
  </view>
</template>
```

## 五、注意事项

### 5.1 SSE 兼容性

| 环境 | 方案 | 说明 |
|---|---|---|
| H5 | `fetch` + `ReadableStream` | 推荐，支持逐 chunk 渲染 |
| App (Android) | `uni.request` + `enableChunked` | 部分版本支持，不支持则降级为全量返回 |
| App (iOS) | `uni.request` + `enableChunked` | 支持有限，建议降级 |
| 微信小程序 | 不支持分块 | 降级为全量返回后解析 |

**降级策略**：App/小程序如不支持 SSE 分块，可改为普通 POST 请求，后端返回完整 JSON 数组：

```json
[
  {"type":"chunk","content":"您好！"},
  {"type":"chunk","content":"请问哪里不舒服？"},
  {"type":"options","items":[{"label":"头痛","value":"我最近头痛"}]},
  {"type":"phase","value":"GREETING"},
  {"type":"done","completed":false,"audio":"base64..."}
]
```

如需此降级接口，后端可新增 `/api/v2/chat/sync` 端点。

### 5.2 音频播放兼容性

| 环境 | 方案 | 说明 |
|---|---|---|
| H5 | `new Audio(blobUrl)` | 直接播放 base64 转的 Blob |
| App | `uni.createInnerAudioContext()` + 临时文件 | base64 写入临时文件后播放 |
| 小程序 | `uni.createInnerAudioContext()` + TTS URL | 不支持 base64，调 `/api/v2/tts` 接口 |

### 5.3 conversationId 管理

- 首次进入页面时生成，格式建议 `conv_{timestamp}_{random}`
- 整个问诊流程（5-15轮）使用同一个 conversationId
- 问诊完成后（`done.completed === true`），重新生成新的 conversationId 开始下一次问诊

### 5.4 错误处理

- 网络断开：提示用户检查网络，提供重试按钮
- 流式中断：`isStreaming` 超时未收到 `done` 事件时，重置状态
- TTS 失败：`audio` 为 null 时静默跳过，不影响文字交互
