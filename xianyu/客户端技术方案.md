## 四、数据库表结构（本地 SQLite）

### 4.1 goodfish_account（闲鱼账号表）

存储本地 cookie 信息。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| goodfish_id | VARCHAR(64) | 闲鱼用户 ID，唯一索引 |
| goodfish_nickname | VARCHAR(128) | 闲鱼昵称 |
| cookie | TEXT | 加密存储的 cookie |
| remark | VARCHAR(256) | 备注 |
| is_valid | BOOLEAN | 是否有效 |
| is_listening | BOOLEAN | 是否正在监听 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 4.2 config（配置表，key-value）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| key | VARCHAR(64) | 配置键，唯一索引 |
| value | TEXT | 配置值 |
| desc | VARCHAR(256) | 配置说明 |

**初始配置项：**

| key | 默认值 | 说明 |
|-----|--------|------|
| max_listen_count | 3 | 最大监听数 |
| slide_window_seconds | 5 | 滑动窗口时长（秒） |
| cloud_backend_url | 打包写死 | 云端后台地址 |
| auth_token | 空 | 管理后台登录 token |
| python_port | 随机 | 本地服务端口 |

## 六、核心模块设计

### 6.1 WebSocket 管理器（websocket_manager.py）

- 维护多账号 WebSocket 连接池
- 每个账号一个 WebSocket 连接
- 断线重连：3次，间隔 5s/10s/15s
- 消息回调：收到消息后交给 message_processor 处理

### 6.2 消息处理器（message_processor.py）

- **消息去重**：按 `message_id` 缓存最近 100 条，重复丢弃
- **滑动窗口**：
  - 按 `buyer_id + item_id` 分组
  - 窗口时长 5 秒（可配置）
  - 窗口内多条消息合并成一条
  - 窗口结束后触发云端调用
- **消息发送**：
  - 收到云端返回的回复后，等待 1-2 秒随机延迟
  - 调用闲鱼 SDK 发送消息
  - 发送失败重试 3 次，间隔 2-3 秒随机

### 6.3 图片处理器（image_processor.py）

> v2.8 调整：图片走 URL，不传 base64；下载与上传由本机完成，云端只存本地磁盘并提供 URL 访问（详见《客户端监听.md》§2.4）。

- 下载：用闲鱼 Cookie 下载图片（超时与重试）
- 转 PNG：统一保存为 PNG（临时文件中转，本机不长期留存）
- 上传：POST /api/ai/image（带登录 token）→ 返回图片 URL
- 张数约束：单次最多 5 张（本地配置项）
- 降级：下载 / 上传失败替换为占位文本 `[图片]`，不阻断流程

### 6.4 云端客户端（cloud_client.py）

- 封装所有云端 API 调用
- 自动带上 auth_token
- 401 自动跳登录页（通过事件通知渲染层）
- 请求失败重试 3 次，间隔 2-3 秒随机
- 连续失败超过 3 次触发"云端不可用"状态

### 6.5 闲鱼客户端（goodfish_client.py）

- 封装开源逆向 SDK
- 提供：cookie 验证、拉取账号信息、拉取商品列表、发送消息、WebSocket 连接
- cookie 加密解密：本地存储时加密，使用时解密

## 七、启动流程

```
1. Electron 启动
2. Electron 主进程启动 Python exe
3. Python exe 启动 FastAPI 服务，绑定 127.0.0.1:随机端口
4. Python 端口写入本地配置，Electron 读取
5. Electron 渲染层加载登录页/主界面
6. 渲染层调本地 API，检查登录态
7. 未登录 → 显示登录页
8. 已登录 → 显示主界面（账号管理页）
```

## 八、打包方案

### 8.1 Python 打包
- 使用 PyInstaller 打包成单 exe
- 包含所有依赖（FastAPI、SQLAlchemy、Pillow 等）
- 输出到 `electron/resources/` 目录

### 8.2 Electron 打包
- 使用 electron-builder 打包成安装包
- 把 Python exe 作为 extraResource 打进去
- 输出 NSIS 安装包（Windows）
- 整体升级：Electron + Python 一起升级

### 8.3 自动升级
- 使用 electron-updater
- 检查更新接口：`/goodfish/version/check`
- 强升：只有"立即更新"按钮
- 非强升："立即更新" + "以后再说"
- 升级时停止所有进程，替换文件，重启
