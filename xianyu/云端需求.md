# 闲鱼自动回复系统 云端管理后台需求

> 版本：v1.0 ｜ 日期：2026-09-21 ｜ 状态：需求确认
> 关联文档：《需求.md》v3.0（本机端需求）

---

## 一、概述

云端管理后台负责 AI 对话的核心业务逻辑：商品管理、提示词管理、模型配置、消息处理。**不包含登录页、会话记录页、设备管理页**（基础脚手架已有，会话记录直接在闲鱼端查看）。

---

## 二、数据库表设计

### 2.1 goodfish_account（goodfish 账号表）

存储本机上报的闲鱼账号信息，**不存储 token**。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| goodfish_id | VARCHAR(64) | 闲鱼用户 ID，唯一索引 |
| goodfish_name | VARCHAR(128) | 闲鱼昵称 |
| remark | VARCHAR(256) | 备注 |
| is_valid | BOOLEAN | 是否有效（token 是否可用） |
| last_active_at | DATETIME | 最后活跃时间 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

**上报时机**：本机添加 token 验证通过后，自动上报到云端。

---

### 2.2 item（商品表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| goodfish_account_id | BIGINT | 关联 goodfish_account.id |
| goodfish_item_id | VARCHAR(64) | 闲鱼商品 ID |
| title | VARCHAR(256) | 商品标题 |
| description | TEXT | 商品描述 |
| price | DECIMAL(10,2) | 价格 |
| stock_status | VARCHAR(32) | 库存状态（现货/可预订等） |
| prompt_content | TEXT | 提示词内容（每个商品单独一套） |
| sync_time | DATETIME | 最后同步时间 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

**索引**：
- `(goodfish_account_id, goodfish_item_id)` 联合唯一索引

**同步策略**：全量同步，按 `goodfish_item_id` upsert，已存在商品保留 `prompt_content` 不被覆盖。

---

### 2.3 prompt_template（提示词模板表）

预设模板库，方便快速把提示词套用到商品。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| name | VARCHAR(128) | 模板名称 |
| content | TEXT | 模板内容（带 `{{变量}}` 占位符） |
| variables | JSON | 变量列表，如 `["商品标题", "商品描述", "买家提问"]` |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

---

### 2.4 llm_provider（大模型供应商表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| name | VARCHAR(64) | 供应商名称（OpenAI / DeepSeek / 通义千问等） |
| base_url | VARCHAR(256) | 接口地址 |
| api_key | VARCHAR(256) | API 密钥（加密存储） |
| status | TINYINT | 状态：1=启用，0=停用 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

---

### 2.5 llm_model（大模型表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| provider_id | BIGINT | 关联 llm_provider.id |
| name | VARCHAR(64) | 模型显示名称（如"GPT-4o"） |
| model_name | VARCHAR(64) | 实际模型名（如"gpt-4o"） |
| temperature | FLOAT | 温度参数，默认 0.7 |
| max_tokens | INT | 最大输出 token 数，默认 2048 |
| status | TINYINT | 状态：1=启用，0=停用 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

**全局启用**：同一时间只有一个启用的模型（status=1），切换模型时自动把其他模型设为停用。

## 三、页面设计

### 3.1 仪表盘

**功能**：纯展示，两个数字卡片
- 账号数：goodfish_account 表总记录数
- 商品数：item 表总记录数

**说明**：不做实时数据、不做趋势图、不做消息统计。

---

### 3.2 商品管理

**列表页**：
- 表格列：商品标题、所属账号、价格、库存状态、最后同步时间、操作
- 筛选：按账号筛选
- 操作按钮：编辑、复制提示词到其他商品、删除

**编辑弹窗/抽屉**：
- 基本信息：标题、描述、价格、库存状态（只读，从同步来）
- 提示词编辑：textarea，支持变量占位符
- 「从模板导入」按钮：弹出提示词模板列表，选择后填入编辑框

**复制提示词到其他商品**：
- 点击后弹出选择对话框
- 选择目标商品（可多选）
- 确认后将当前商品的 prompt_content 覆盖到目标商品

---

### 3.3 提示词管理

**列表页**：
- 表格列：模板名称、变量数、创建时间、操作
- 操作按钮：编辑、删除

**编辑弹窗/抽屉**：
- 模板名称
- 模板内容（textarea）
- 变量列表（手动添加/删除变量名）

**用途**：作为预设模板库，在商品编辑页可以「从模板导入」快速填入提示词。

---

### 3.4 模型管理

**供应商管理**：
- 表格列：供应商名称、接口地址、状态、操作
- 操作按钮：编辑、测试连接、启用/停用、删除
- 新增/编辑弹窗：名称、base_url、api_key

**模型管理**：
- 表格列：模型名称、所属供应商、状态、操作
- 操作按钮：编辑、启用/停用、删除
- 新增/编辑弹窗：所属供应商下拉、模型显示名、实际模型名、temperature、max_tokens

**测试连接**：
- 点击后用该供应商配置调一个轻量请求，验证 api_key 和 base_url 是否可用

**全局启用规则**：
- 同一时间只能有一个 llm_model 是启用状态
- 启用某个模型时，自动把其他模型设为停用

## 四、核心业务流程

### 4.1 消息处理流程（无人工审核）

```
本机上报消息
    携带：goodfish_id, goodfish_item_id, buyer_id, session_id, message
    ↓
云端：根据 goodfish_item_id 查找商品
    ↓
商品存在 → 拿到商品的 prompt_content
商品不存在 → 使用默认通用提示词（如果有的话）
    ↓
渲染提示词变量：
  - {{商品标题}} → 商品.title
  - {{商品描述}} → 商品.description
  - {{买家提问}} → 买家消息内容
    ↓
调用当前启用的 llm_model → 生成 AI 回复
    ↓
直接下发发送指令到本机
    携带：session_id, content(AI回复)
    ↓
本机调用闲鱼接口发送
```

---

### 4.2 商品同步流程

```
本机点击"同步商品"
    ↓
本机调闲鱼接口，全量拉取该账号下所有商品
    ↓
本机上报到云端接口
    携带：goodfish_id, 商品列表数组
    ↓
云端处理：
  1. 根据 goodfish_id 找到 goodfish_account
  2. 遍历商品列表，按 goodfish_item_id upsert
  3. 已存在的商品：更新 title/description/price/stock_status/sync_time，保留 prompt_content
  4. 新商品：插入完整记录，prompt_content 为空
    ↓
返回同步结果（新增数、更新数）
```

---

### 4.3 账号上报流程

```
本机添加 token 验证通过
    ↓
本机调闲鱼接口获取账号信息（goodfish_id, goodfish_name）
    ↓
本机上报到云端接口
    携带：goodfish_id, goodfish_name, remark
    ↓
云端：按 goodfish_id upsert
  - 已存在：更新 goodfish_name, remark, is_valid=true
  - 新账号：插入完整记录
```

## 五、API 接口清单（本机调用云端）

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/account/report | POST | 上报 goodfish 账号信息 |
| /api/item/sync | POST | 同步商品列表 |
| /api/message/receive | POST | 上报买家消息 |
| /api/message/send_result | POST | 上报消息发送结果 |

> 云端管理后台自身的 CRUD 接口（商品管理、提示词管理、模型管理）属于脚手架范畴，不在此需求内。

## 六、验收标准

| 编号 | 验收项 | 判定标准 |
|------|--------|----------|
| A1 | 仪表盘 | 展示账号总数、商品总数，纯静态数字卡片 |
| A2 | 商品管理 | 支持列表、编辑、复制提示词到其他商品 |
| A3 | 提示词管理 | 支持模板 CRUD，可在商品编辑页导入模板 |
| A4 | 模型管理 | 支持供应商和模型 CRUD，全局仅一个启用模型 |
| A5 | 消息处理 | 上报消息后自动调模型生成回复并下发，无人工审核环节 |
| A6 | 商品同步 | 全量同步，已存在商品保留自定义提示词 |
| A7 | 账号上报 | 添加 token 验证通过后自动上报云端，不存 token |
