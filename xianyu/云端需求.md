# 闲鱼自动回复系统 云端管理后台需求

> 版本：v1.4 ｜ 日期：2026-09-29 ｜ 状态：需求确认
> 关联文档：《客户端需求.md》、《云端技术方案.md》（表结构与技术栈）

---

## 一、概述

云端管理后台负责 AI 对话的核心业务逻辑：商品管理、提示词管理、模型配置、消息处理、授权校验。**不包含登录页、会话记录页、设备管理页**（基础脚手架已有，会话记录直接在闲鱼端查看）。

---

## 二、业务数据说明

云端存储以下业务数据：

1. **goodfish 账号**：本机上报的闲鱼账号信息（闲鱼 ID、昵称、备注、是否有效、最后活跃时间），**不存储 cookie**
2. **商品库**：商品信息（标题、描述、价格、库存状态、关联账号、提示词内容）
3. **提示词模板**：**系统内置**模板（放商品服务 Spring 配置文件，只读），供商品编辑时「从模板导入」
4. **大模型配置**：供应商信息（接口地址、密钥）、模型参数（温度、最大输出）
5. **客户端版本管理**：版本号、更新说明、安装包文件、是否强制更新

> 具体表结构设计见《云端技术方案.md》。

## 三、页面设计

### 3.1 仪表盘

**功能**：纯展示，两个数字卡片
- 账号数：goodfish 账号总记录数
- 商品数：商品库总记录数

**说明**：不做实时数据、不做趋势图、不做消息统计。

---

### 3.2 商品管理

**列表页**：
- 表格列：商品标题、所属账号、价格、库存状态、最后同步时间、操作
- 筛选：按账号筛选
- 操作按钮：编辑、复制提示词到其他商品、删除

**编辑弹窗/抽屉**：
- 基本信息：标题、描述、价格、库存状态（只读，从同步来）
- 提示词编辑：textarea，支持变量占位符
- 「从模板导入」按钮：弹出提示词模板列表，选择后填入编辑框

**复制提示词到其他商品**：
- 点击后弹出选择对话框
- 选择目标商品（可多选）
- 确认后将当前商品的提示词内容覆盖到目标商品

---

### 3.3 提示词管理

> **v1.5 调整**：提示词模板改为**系统内置只读**（放在商品服务的 Spring 配置文件 `goodfish-prompt-templates.yml` 中），后台**不再提供模板的新增 / 编辑 / 删除**。
>
> 提示词本身仍**随商品直接关联**（每个商品一套：系统提示词 + 议价/技术/默认三个场景提示词 + 高级设置），在商品编辑页维护。

**列表页**：
- 表格列：模板编码、模板名称、变量数（**只读展示**）
- 操作按钮：**仅「导入到商品」**（无编辑、无删除）

**用途**：作为**内置预设库**，在商品编辑页可以「从模板导入」快速填入该商品的提示词；导入即复制，之后商品上的提示词可独立编辑，不受模板影响。

**模板调整方式**：修改商品服务的配置文件后随版本发布，**不通过页面维护**。

---

### 3.4 模型管理

**供应商管理**：
- 表格列：供应商名称、接口地址、状态、操作
- 操作按钮：编辑、测试连接、启用/停用、删除
- 新增/编辑弹窗：名称、base_url、api_key

**模型管理**：
- 表格列：模型名称、所属供应商、状态、操作
- 操作按钮：编辑、启用/停用、删除
- 新增/编辑弹窗：所属供应商下拉、模型显示名、实际模型名、temperature、max_tokens

**测试连接**：
- 点击后用该供应商配置调一个轻量请求，验证 api_key 和 base_url 是否可用

**全局启用规则**：
- 同一时间只能有一个模型是启用状态
- 启用某个模型时，自动把其他模型设为停用

---

### 3.5 版本管理

**列表页**：
- 表格列：版本号、更新说明、是否强制更新、发布时间、操作
- 操作按钮：发布新版本、设为强制更新/取消、删除

**发布新版本**：
- 上传安装包文件
- 填写版本号（如 v1.0.0）
- 填写更新说明
- 选择是否强制更新

**检查更新接口**：
- 客户端调用此接口，传入当前版本号
- 返回最新版本信息：版本号、更新说明、是否强制更新、安装包下载地址

## 四、核心业务流程

### 4.1 消息处理流程（无人工审核）

```
本机上报消息
    携带：message_id, goodfish_id, goodfish_item_id, buyer_id, session_id, message, msg_type, image_url(图片消息时，为客户端预先上传到云端后取得的图片 URL)
    ↓
云端：根据 goodfish_item_id 查找商品
    ↓
商品不存在 → 返回错误码，本机不发送、不回复
    ↓
商品存在 → 拿到商品的提示词内容
    ↓
以「商品ID + 买家ID」作为对话ID，拉取历史对话上下文
    ↓
渲染提示词变量：
  - {{商品标题}} → 商品标题
  - {{商品描述}} → 商品描述
  - {{买家提问}} → 买家消息内容
    ↓
调用当前启用的模型 → 生成 AI 回复
    ↓
保存本轮对话到历史（买家消息 + AI 回复）
    ↓
直接返回回复内容到本机
    携带：session_id, content(AI回复)
    ↓
本机等待随机延迟后调用闲鱼接口发送
```

> **对话历史维护**：云端以「商品ID + 买家ID」作为对话 ID 维护上下文，客户端不负责传历史。

---

### 4.2 商品同步流程

```
本机点击"同步商品"
    ↓
本机调闲鱼接口，全量拉取该账号下所有商品
    ↓
本机上报到云端接口
    携带：goodfish_id, 商品列表数组
    ↓
云端处理：
  1. 根据 goodfish_id 找到对应账号
  2. 遍历商品列表，按 goodfish_item_id upsert
  3. 已存在的商品：更新标题/描述/价格/库存状态/同步时间，保留已有提示词
  4. 新商品：插入完整记录，提示词为空
    ↓
返回同步结果（新增数、更新数）
```

> **同步规则**：只增不删。本机删除的商品，云端不会自动删除；需要删除时由用户在云端管理后台手动操作。

---

### 4.3 账号上报流程

```
本机添加 cookie 验证通过
    ↓
本机调闲鱼接口获取账号信息（goodfish_id, goodfish_nickname）
    ↓
本机上报到云端接口
    携带：goodfish_id, goodfish_nickname, remark
    ↓
云端：按 goodfish_id upsert
  - 已存在：更新昵称、备注、标记为有效
  - 新账号：插入完整记录
```

---

### 4.4 授权校验接口

**接口说明**：客户端启动时和运行中定时调用，判断当前登录账号是否有使用权限。

```
客户端调授权校验接口
    携带：登录 token
    ↓
云端：根据 token 找到当前用户
    ↓
校验该用户的授权状态：
  - 有效（在授权期内）→ 返回 success
  - 无效（过期/未授权）→ 返回错误码，客户端冻结应用
```

**说明**：授权状态直接复用 RuoYi 用户表，后续可扩展为独立的授权管理（到期时间、授权类型等）。

## 五、验收标准

| 编号 | 验收项 | 判定标准 |
|------|--------|----------|
| A1 | 仪表盘 | 展示账号总数、商品总数，纯静态数字卡片 |
| A2 | 商品管理 | 支持列表、编辑、复制提示词到其他商品 |
| A3 | 提示词管理 | 内置模板**只读**，可在商品编辑页「从模板导入」；不做模板 CRUD |
| A4 | 模型管理 | 支持供应商和模型 CRUD，全局仅一个启用模型 |
| A5 | 消息处理 | 上报消息后自动调模型生成回复并下发，无人工审核环节 |
| A6 | 商品同步 | 全量同步，已存在商品保留自定义提示词 |
| A7 | 账号上报 | 添加 cookie 验证通过后自动上报云端，不存 cookie |
| A8 | 版本管理 | 支持发布新版本、上传安装包、设置强制更新 |
| A9 | 检查更新接口 | 客户端调用返回最新版本信息（含下载地址、是否强升） |
| A10 | 商品不存在不回复 | 云端找不到商品时返回错误码，本机不发送不回复 |
| A11 | 商品同步只增不删 | 同步时只新增/更新，不删除云端已有商品 |
| A12 | 图片消息处理 | 提供图片上传接口（客户端上传 PNG，存服务器本地磁盘返回 URL）；接收消息中的图片 URL，调用多模态模型识别 |
| A13 | 对话历史维护 | 以商品ID+买家ID为对话ID维护上下文，回复连贯 |
| A14 | 授权校验接口 | 客户端调用可返回授权状态，无效时返回错误码 |
