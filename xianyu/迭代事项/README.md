# 迭代事项说明

本目录收纳所有「计划中、未进入当前需求范围」的工作项，与《需求/》《技术方案/》目录中的正式文档区分。

## 目录结构

| 子目录 | 定位 | 内容 |
|---|---|---|
| [todo/](todo/) | **当前待办**：已确认要做、尚未实现的小项 | [TODO.md](todo/TODO.md) |
| [下期迭代/](下期迭代/) | **下一迭代的规划**：已成文的功能规划，本期不实现 | [goodfish-迭代2.md](下期迭代/goodfish-迭代2.md) |

## 使用约定

- 新增待办 → 放入 `todo/`，一事一条，注明日期
- 新一轮迭代启动规划 → 放入 `下期迭代/`，一份迭代一份文档
- 迭代规划转正后：需求部分迁入 [需求/](../需求/)、技术方案部分迁入 [技术方案/](../技术方案/)，并更新根目录 [文档总览.md](../文档总览.md) 的映射表
