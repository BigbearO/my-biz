### 2. 大模型 Token 消耗统计

**描述**：每次调用大模型对话时，记录消耗的 token 数量（输入 token、输出 token、总 token），入库存储。

**涉及表**：新增一张 `llm_usage_log` 表，字段包括：
- 对话 ID（商品ID + 买家ID）
- 调用时间
- 输入 token 数
- 输出 token 数
- 总 token 数
- 调用模型
- 耗时（毫秒）

**用途**：后续可做用量统计、成本核算、调用趋势分析。

### 3. 回复决策日志（ai_reply_log）归档/清理策略评估

**描述**：`ai_reply_log` 已裁定**长期保留、不做清理**（与对话历史一并留存，是排障与后续统计的主依据），当前不实现任何清理任务，也无需相关索引。

**后续关注**：数据量持续增长后，评估归档/分区/清理策略（如按 `created_at` 归档历史数据到冷表），届时再实现。

**描述**：本期商品编辑页只支持**系统提示词（`system_prompt`）+ 高级设置（最大回复字数 / 温度 / 最大输出 token）**；`goodfish_item_prompt` 表中的 `price_prompt` / `tech_prompt` / `default_prompt` 三个场景提示词字段保留但**页面不提供输入、留空**。
