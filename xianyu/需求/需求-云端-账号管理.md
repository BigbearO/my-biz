# 需求-云端-账号管理

> 来源：《云端需求.md》§二 业务数据说明（goodfish 账号部分）、§4.3 账号上报流程（内容重组收录，原文件保留未动）
> 关联：[技术方案-云端-客户端元数据服务](../技术方案/技术方案-云端-客户端元数据服务.md)

## 一、功能概述（总）

### 1.1 功能定位

账号管理负责云端对 goodfish（闲鱼）账号数据的管理：本机添加 cookie 验证通过后自动上报账号信息到云端，云端按 goodfish_id upsert 维护账号记录，供商品归属、仪表盘账号数统计等使用。云端**不存储 cookie**。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|---|---|---|
| 1 | 账号数据管理 | 云端存储本机上报的闲鱼账号信息（闲鱼 ID、昵称、备注、最后活跃时间） |
| 2 | 账号上报流程 | 本机添加 cookie 验证通过后上报账号信息，云端按 goodfish_id upsert |
| 3 | 云端停用 / 启用账号 | 在云端账号管理页停用闲鱼账号（可再次启用）；★账号**只停用、不删除** |
| 4 | 监听占用 | 同一闲鱼账号同一时刻**只允许一台设备监听**（Redis 租约校验），见 §2.4 |

### 1.3 功能边界

- cookie 只保留在本机，云端不存储、不上报 cookie；**账号是否有效等 cookie 相关状态只在本地维护，云端不体现、不展示**。
- 账号的添加、监听控制等操作在客户端完成，云端只接收上报数据。
- **闲鱼账号在云端只停用、不删除**：客户端删除账号只删本地 cookie，不联动云端（见[需求-客户端-账号管理.md](需求-客户端-账号管理.md)）；云端停用账号**不级联删商品**，已同步的商品全部保留、仍可查看与编辑。
- 后台「账号管理」页面在菜单中的位置见[需求-云端-仪表盘与后台页面.md](需求-云端-仪表盘与后台页面.md)。

## 二、功能详述（分）

### 2.1 账号数据

云端存储本机上报的闲鱼账号信息：闲鱼 ID、昵称、备注、最后活跃时间，**不存储 cookie**；**不记录是否有效**（cookie 有效性只在本地维护）。

### 2.2 账号上报流程

```
本机添加 cookie 验证通过
    ↓
本机调闲鱼接口获取账号信息（goodfish_id, goodfish_nickname）
    ↓
本机上报到云端接口
    携带：goodfish_id, goodfish_nickname, remark
    ↓
云端：按 goodfish_id upsert
  - 已存在：更新昵称、备注
  - 新账号：插入完整记录
```

### 2.3 云端停用 / 启用账号（★账号只停用、不删除）

```
在云端账号管理页停用账号
    ↓
标记该账号为「停用」
    ↓
影响范围：
  - 该账号的**商品同步被拒绝**（云端返回 40404「账号已停用」，客户端提示联系管理员）
  - 已同步的商品**全部保留**，仍可查看、编辑提示词、参与 AI 回复
  - 客户端本地的该账号记录与监听**不受直接影响**（客户端不感知云端停用状态）
    ↓
再次启用 → 恢复同步能力
```

> **为什么只停用不删除**：商品同步规则是「只增不删」，一旦某账号同步过商品，"先删完商品才能删账号"在该账号商品较多时事实上走不通；且账号与其历史商品数据有留存价值，因此改为停用。
>
> **客户端重新添加同一账号**：上报接口按 `goodfish_id` upsert（更新昵称/备注），但**不复活停用状态**——停用由管理员控制。

### 2.4 监听占用（跨设备去重）★

同一个闲鱼账号只允许**一台设备**同时监听（否则两端都会收到同一条买家消息 → 重复回复）：

| 项 | 约定 |
|---|---|
| 判定方式 | 云端 **Redis 账号级租约**：`goodfish:listen:{goodfish_id}` |
| 申请时机 | 客户端点「开始监听」**之前**申请；已被其他设备占用 → 拒绝（`409`） |
| 续期 | 监听期间每 **30s** 续期一次；租约 **90s** |
| 释放 | 停止监听 / 退出应用时主动释放；进程崩溃由 TTL 自动兜底 |
| 接口不可用 | **降级放行**（不阻断监听），记 WARN |

> 接口与实现见 [技术方案-云端-客户端元数据服务](../技术方案/技术方案-云端-客户端元数据服务.md) §2.4；客户端流程见 [需求-客户端-监听控制](../需求/需求-客户端-监听控制.md) §2.1。

## 三、业务规则与约束

1. 云端账号记录以 goodfish_id 为唯一标识做 upsert。
2. 已存在账号：更新昵称、备注。
3. 新账号：插入完整记录。
4. 云端不存储 cookie，也不记录账号是否有效（cookie 有效性只在本地维护）。
5. 云端账号**只停用、不删除**：停用**不校验商品数**、**不级联删商品**；停用后该账号的商品同步被拒绝（40404），已同步的商品全部保留、仍可查看编辑与参与 AI 回复。

## 四、异常与边界场景

| 场景 | 处理要求 |
|---|---|
| 上报的账号在云端已存在 | 更新昵称、备注 |
| 上报的账号为云端新账号 | 插入完整记录 |
| 云端停用账号时该账号下仍有商品 | **允许停用**：商品全部保留、不级联删除（★账号不删除，无需先处理商品） |
| 客户端删除账号 | 只删本地 cookie，云端账号记录不变（如需**停用**闲鱼账号，到云端账号管理页操作） |
