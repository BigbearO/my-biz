## 一、功能概述（总）

### 1.1 功能定位

云端管理页通过内嵌 WebView 打开**云端后台地址**（商品/提示词/模型），用户无需离开客户端即可进入业务配置管理，配合单入口体验。**plus-ui 是独立部署的云端应用**，其页面、登录与数据全部自理，客户端不做任何注入或改造。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|------|--------|------|
| F1 | 内嵌 WebView 加载 | 菜单项「云端管理」点击后，右侧内容区加载内嵌 WebView，地址为云端后台地址 |
| F2 | 后台自身登录 | WebView 内的登录与登录态**由云端后台（plus-ui）自行处理**，客户端不注入 token、不干预 |
| F3 | WebView 内管理操作 | 用户可在 WebView 内完成商品、提示词、模型的全部管理操作 |

### 1.3 功能边界

- 云端管理后台自身的功能（商品/提示词/模型管理、登录、会话）归云端，见 [需求-云端-仪表盘与后台页面](需求-云端-仪表盘与后台页面.md)；**客户端不定义、不改造 plus-ui**。
- 云端后台地址的配置方式归 [需求-客户端-安全与本地配置](需求-客户端-安全与本地配置.md)（打包时写死，不存本地配置）
- 本文件只负责内嵌加载与加载失败兜底，不定义云端后台内部页面与登录流程
- **架构边界**：本页内嵌的是**独立部署的云端后台（plus-ui）**，客户端**不内嵌 plus-ui 前端工程**；客户端的本地功能页（账号管理 / 日志 / 设置）由 Electron 自身提供，数据经**内嵌 Python 本地服务 + SQLite**，不在本文件范围

## 二、功能详述（分）

### 2.1 云端管理页规则

- 菜单项「云端管理」点击后，右侧内容区加载内嵌 WebView
- WebView 地址为云端后台地址（打包时写死）
- 后台的登录与登录态由 plus-ui 自行处理（客户端**不做 token 注入**）
- 用户可在 WebView 内完成商品、提示词、模型的全部管理操作

## 三、业务规则与约束

- WebView 地址为云端后台地址（打包时写死，不存本地配置）
- **客户端不改动 plus-ui**：不注入请求头、不拦截响应、不要求其调整路由或登录逻辑
- **各自登录**：客户端自身的登录（Electron 登录页）与云端后台（plus-ui）的登录是**两套独立登录态，互不通用**；进入「云端管理」时若后台未登录，由 plus-ui 自行引导登录
- ★**三者完全独立、互不影响**：客户端自身的登录态（Python 持有的管理后台 token）、客户端的**授权冻结状态**、WebView 内 plus-ui 的登录态，是**相互独立的三件事**，互不同步：
  - WebView 内 plus-ui 未登录 / 登录态过期 → 由 plus-ui 自行引导登录，客户端**不介入、不注入 token**；
  - 客户端授权失效被冻结 → 冻结的是**整个客户端**（只能点退出），WebView 内的一切操作随之不可用；**授权冻结即账号冻结**——所有监听已停止，不再发起任何云端调用（见 [需求-云端-登录与授权校验](需求-云端-登录与授权校验.md) §2.3）
- 商品、提示词、模型的全部管理操作均在 WebView 内完成，客户端不重复实现管理界面

## 四、异常与边界场景

| 场景 | 处理要求 |
|------|----------|
| 云端后台地址不可达 / WebView 加载失败 | WebView 区域显示"云端管理加载失败"提示 + 重试按钮，不影响其他页面功能 |
| WebView 内登录态过期（401） | 由 plus-ui 自身处理（跳其登录页），客户端不介入 |
