## 一、功能概述（总）

### 1.1 功能定位

云端管理页通过内嵌 WebView 把云端管理后台（商品/提示词/模型）直接嵌入客户端主界面，用户无需离开客户端即可完成全部业务配置管理，配合单入口体验。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|------|--------|------|
| F1 | 内嵌 WebView 加载 | 菜单项「云端管理」点击后，右侧内容区加载内嵌 WebView |
| F2 | 登录态透传 | 本地存储的 token 经 `Authorization` 请求头注入（OAuth2 风格），WebView 内请求自动携带 |
| F3 | WebView 内管理操作 | 用户可在 WebView 内完成商品、提示词、模型的全部管理操作 |

### 1.3 功能边界

- 云端管理后台自身的功能（商品/提示词/模型管理）归《云端需求.md》：[../云端需求.md](../云端需求.md)
- 登录 token 的获取流程归 [需求-客户端-应用框架与启动登录](需求-客户端-应用框架与启动登录.md)，运行中 token 过期处理归 [需求-客户端-异常与容错](需求-客户端-异常与容错.md)
- 云端后台地址的配置方式归 [需求-客户端-安全与本地配置](需求-客户端-安全与本地配置.md)（打包时写死，不存本地配置）
- 本文件只负责内嵌加载与登录态透传，不定义云端后台内部页面
- **架构边界**：本页内嵌的是**云端部署的管理后台（plus-ui，纯云端应用）**，客户端**不内嵌 plus-ui 前端工程**；客户端的本地功能页（账号管理 / 日志 / 设置）由 Electron 自身提供，数据经**内嵌 Python 本地服务 + SQLite**，不在本文件范围

## 二、功能详述（分）

### 2.1 云端管理页规则

- 菜单项「云端管理」点击后，右侧内容区加载内嵌 WebView
- WebView 地址为云端管理后台首页
- 登录态经 `Authorization` 请求头注入（OAuth2 风格）：Electron 对云端后台域名的请求统一注入请求头，机制见 [技术方案-客户端-云端管理内嵌](../技术方案/技术方案-客户端-云端管理内嵌.md)
- 用户可在 WebView 内完成商品、提示词、模型的全部管理操作

## 三、业务规则与约束

- WebView 地址为云端管理后台首页（地址打包时写死，不存本地配置）
- 登录态经 `Authorization` 请求头注入自动带上（**不用 URL 参数**，避免 token 暴露在地址栏；也不用 cookie 注入）
- 商品、提示词、模型的全部管理操作均在 WebView 内完成，客户端不重复实现管理界面

## 四、异常与边界场景

| 场景 | 处理要求 |
|------|----------|
| 运行中登录态过期（调云端接口返回 401） | 自动跳转登录页，要求重新登录，见 [需求-客户端-异常与容错](需求-客户端-异常与容错.md) |
| 云端后台不可访问 | 客户端侧无特殊处理，遵循 [需求-客户端-异常与容错](需求-客户端-异常与容错.md) 的云端不可用策略 |
