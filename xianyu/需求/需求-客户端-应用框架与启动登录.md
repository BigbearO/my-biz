## 一、功能概述（总）

### 1.1 功能定位

应用框架与启动登录是客户端的入口层：以 Electron 桌面应用作为唯一用户感知入口，承载登录鉴权、授权校验与主界面框架，解决"单入口使用、统一布局导航"的体验问题。系统基于大模型实现闲鱼消息智能自动回复，配套商品管理、提示词管理、模型管理能力，采用**「本地监听代理 + 云端管理后台」分离架构**。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|------|--------|------|
| F1 | 单入口应用框架 | Electron 桌面应用统一入口，主进程守护 Python 本地服务（仅绑定 127.0.0.1），Vue 渲染层提供左侧菜单 + 右侧内容区 |
| F2 | 启动登录流程 | 启动时依次通过「管理后台登录」与「授权校验」两道门槛，通过后进入主界面 |
| F3 | 主界面布局 | 标准管理系统布局：左侧固定宽度菜单（账号管理/云端管理/日志/设置）+ 右侧内容区切换 |

## 二、功能详述（分）

### 2.1 项目概述与核心设计原则

**项目目标**：基于大模型实现闲鱼消息智能自动回复，配套商品管理、提示词管理、模型管理能力。采用**「本地监听代理 + 云端管理后台」分离架构**，在保证闲鱼账号凭证安全的前提下，实现 Web 化统一配置管理。

**风险提示**：

- 闲鱼官方禁止第三方逆向工具、自动应答脚本，本方案仅用于技术研究，使用存在账号封禁风险
- 严禁用于商业用途、多账号批量运营
- 开源逆向 SDK 存在协议升级失效的可能，需持续维护适配

**核心设计原则**：

| 原则 | 说明 |
|------|------|
| **敏感凭证本地化** | 闲鱼 Cookie 仅存本地，加密存储，永不离机 |
| **业务配置云端化** | 商品、提示词、模型配置统一云端管理 |
| **风险隔离原则** | 闲鱼交互逻辑与业务管理逻辑彻底分离 |
| **单入口体验** | Electron 统一入口，用户只启动一个应用 |

### 2.2 整体架构

```
Electron 桌面应用（单入口，唯一用户感知）
├── Vue 渲染层（左侧菜单 + 右侧内容区，标准管理系统布局）
│   ├── 左侧菜单
│   │   ├── 账号管理
│   │   ├── 云端管理（商品/提示词/模型，WebView 内嵌）
│   │   └── 日志
│   └── 右侧内容区（根据菜单切换）
└── 主进程
    └── 守护 Python exe（本地服务，仅绑定 127.0.0.1）
        ├── 本地 SQLite 数据库
        ├── 闲鱼 WebSocket 监听
        └── 消息收发 HTTP 接口
```

### 2.3 启动流程

```
1. 打开 Electron 应用
2. 调云端后台接口，检查登录态
3. 401（未登录）→ 跳转管理系统登录页（全屏登录，不显示主界面）
4. 登录成功 → 保存登录 token
5. 检查更新（★ 在授权校验之前）：自动调检查更新接口
   - 已是最新 → 继续
   - 有新版本 → 按强升/非强升弹更新提示（流程见 需求-客户端-设置与自动升级）
   - 检查更新接口不可用 → 不阻断，继续下一步
6. 调授权校验接口，检查账号是否有使用权限
   - 授权有效 → 进入主界面（默认选中「账号管理」菜单）
   - 授权过期/无权限 → 弹窗提示"授权已过期"，应用冻结，只能点退出
   - 云端接口不可用 → 弹窗提示"服务器异常，请联系管理员"，应用冻结
```

> 说明：第一道门槛是**管理后台账号**，第二道门槛是**授权校验**。登录成功后拿到的 token 存储在本机，供 Electron 和 Python 两端共用。
>
> **重启后监听状态**：应用重启后不自动恢复监听，所有账号都是"未监听"状态，需要用户手动点「开始监听」。

### 2.4 主界面布局

标准管理系统布局：左侧固定宽度菜单 + 右侧内容区。

**左侧菜单**：

| 菜单项 | 说明 |
|--------|------|
| 账号管理 | 本地功能，cookie 列表页（默认首页） |
| 云端管理 | 内嵌 WebView 加载云端管理后台（商品/提示词/模型） |
| 日志 | 本地运行日志查看 |
| 设置 | 应用设置、检查更新 |

**右侧内容区**：根据左侧菜单选中项切换内容，每个页面独立。

## 三、业务规则与约束

- 启动流程存在两道门槛：第一道是**管理后台账号**（登录态检查），第二道是**授权校验**（使用权限检查）
- 启动时**自动检查更新**发生在**授权校验之前**（登录成功之后）；检查更新接口不可用不阻断启动
- 登录成功后拿到的 token 存储在本机，供 Electron 和 Python 两端共用
- 应用重启后不自动恢复监听，所有账号都是"未监听"状态，需要用户手动点「开始监听」
- 授权过期/无权限、或启动时云端接口不可用，应用冻结，只能点退出
- 授权校验通过后进入主界面，默认选中「账号管理」菜单
- 本地服务（Python exe）仅绑定 127.0.0.1

## 四、异常与边界场景

| 场景 | 处理要求 |
|------|----------|
| 启动时检查登录态返回 401（未登录） | 跳转管理系统登录页（全屏登录，不显示主界面） |
| 启动时检查更新接口不可用 | 不阻断启动，继续进入授权校验流程 |
| 授权校验返回授权过期/无权限 | 弹窗提示"授权已过期"，应用冻结，只能点退出 |
| 启动时云端接口不可用 | 弹窗提示"服务器异常，请联系管理员"，应用冻结 |
| 应用重启 | 不自动恢复监听，所有账号都是"未监听"状态 |

## 五、验收标准

| 编号 | 验收项 | 判定标准 |
|------|--------|----------|
| A1 | 单入口 | 只安装/启动一个应用即可完成全部操作 |
| A2 | 登录门槛 | 未登录管理后台时，无法进入主界面 |
| A3 | 管理系统布局 | 左侧菜单 + 右侧内容区，四个菜单项可正常切换 |
| A25 | 重启不自动恢复监听 | 重启应用后所有账号都是未监听状态，需手动启动 |
| A40 | 启动时授权校验 | 启动时校验授权状态，过期/无权限则冻结应用 |
