# 需求-云端-商品同步

## 一、功能概述（总）

### 1.1 功能定位

商品同步是本机与云端之间的商品数据同步流程：本机点击「同步商品」后全量拉取该账号下所有商品并上报云端，云端按 goodfish_item_id upsert 入库，形成云端商品库数据，是商品管理功能的数据来源。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|---|---|---|
| 1 | 全量拉取与上报 | 本机调闲鱼接口全量拉取该账号下所有商品，上报到云端接口 |
| 2 | 云端 upsert 入库 | 遍历商品列表，按 goodfish_item_id 更新已有商品 / 插入新商品 |
| 3 | 同步结果返回 | 返回同步结果（新增数、更新数） |

### 1.3 功能边界

- 本流程由本机手动触发（点击「同步商品」）；客户端侧交互见[客户端需求.md](../客户端需求.md) §九 商品同步。
- 同步入库后的商品维护（编辑提示词、复制提示词、删除）归[需求-云端-商品管理.md](需求-云端-商品管理.md)。
- 同步只增不删：云端不随同步删除商品，删除由用户在云端管理后台手动操作。

## 二、功能详述（分）

### 2.1 商品同步流程

```
本机点击"同步商品"
    ↓
本机调闲鱼接口，全量拉取该账号下所有商品
    ↓
本机上报到云端接口
    携带：goodfish_id, 商品列表数组
    ↓
云端处理：
  1. 根据 goodfish_id 经 gRPC GetAccountByGoodfishId 找到对应账号
     （找不到 → **直接抛出异常 40403，同步失败，不继续运行**）
  1b. 校验账号状态：status = disabled → **直接抛出异常 40404，同步失败**
  2. 遍历商品列表，按 goodfish_item_id upsert
  3. 已存在的商品：更新标题/描述/价格/库存状态/同步时间，保留已有提示词
  4. 新商品：插入完整记录，提示词为空
    ↓
返回同步结果（新增数、更新数）
```

## 三、业务规则与约束

1. 云端根据 goodfish_id 找到对应账号，遍历商品列表，按 goodfish_item_id upsert。
2. 已存在的商品：更新标题/描述/价格/库存状态/同步时间，保留已有提示词。
3. 新商品：插入完整记录，提示词为空。
4. **同步规则**：只增不删。本机删除的商品，云端不会自动删除；需要删除时由用户在云端管理后台手动操作。
5. **账号前置**：同步的账号必须已上报云端（添加账号验证通过后自动上报）；账号在云端不存在时同步直接抛出异常、整体失败，不部分入库。

## 四、异常与边界场景

| 场景 | 处理要求 |
|---|---|
| 商品在云端已存在 | 更新标题/描述/价格/库存状态/同步时间，保留已有提示词 |
| 商品为云端新商品 | 插入完整记录，提示词为空 |
| 本机已删除的商品 | 云端不会自动删除；需要删除时由用户在云端管理后台手动操作 |
| 同步的账号在云端不存在（未上报 / 上报失败） | 直接抛出异常（`40403`），同步整体失败，不继续落库；客户端提示「**账号不存在，请联系管理员**」——本地已有该账号却查不到云端记录属异常态，**不提供自助修复入口** |
| 同步的账号已被云端停用 | 直接抛出异常（`40404`），同步整体失败，不继续落库；客户端提示「**账号已停用，请联系管理员**」 |

## 五、验收标准

| 编号 | 验收项 | 判定标准 |
|------|--------|----------|
| A6 | 商品同步 | 全量同步，已存在商品保留自定义提示词 |
| A11 | 商品同步只增不删 | 同步时只新增/更新，不删除云端已有商品 |
