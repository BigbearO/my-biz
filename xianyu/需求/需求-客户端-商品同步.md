## 一、功能概述（总）

### 1.1 功能定位

商品同步把闲鱼账号下的商品数据从闲鱼侧全量拉取并推送到云端后台存储，为消息回复时的商品上下文匹配提供数据基础；入口位于账号管理页每个 cookie 详情页。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|------|--------|------|
| F1 | 手动全量同步 | cookie 详情**弹窗**内「同步商品」按钮触发，全量拉取该账号所有商品并推送云端 |
| F2 | 同步交互反馈 | 按钮置灰、后台异步执行、完成后/失败时 toast 提示 |
| F3 | 同步字段透传 | 闲鱼接口返回什么就推什么，不做过滤 |

### 1.3 功能边界

- 商品数据在云端的管理（增删改查、上下文匹配使用）归云端管理后台，客户端只负责拉取与推送
- 消息回复时如何用商品 ID 匹配商品库归 [需求-客户端-消息自动回复](需求-客户端-消息自动回复.md)
- 添加 cookie 验证通过后自动触发一次全量商品同步为 TODO 暂不做，见本文件第六节

## 二、功能详述（分）

### 2.1 功能说明

- 「同步商品」按钮位于 cookie **详情弹窗**内（账号管理页点「详情」打开，见 [需求-客户端-账号管理](需求-客户端-账号管理.md) §2.2）
- 点击后本机调闲鱼接口，**全量拉取**该账号下所有商品
- 拉取到的全部数据推送到云端后台存储
- 云端用于后续消息回复时的商品上下文匹配

### 2.2 同步方式

- 点击「同步商品」后，按钮变灰提示"正在同步..."
- 后台异步执行同步，不阻塞界面
- 同步完成后弹出 toast 提示："同步完成，新增 X 个，更新 X 个"
- 同步过程中重复点击不生效（按钮置灰）
- 同步失败时弹出 toast 提示"同步失败，请重试"，下次点同步重新全量拉取

### 2.3 同步字段

商品 ID、商品标题、商品描述、价格、库存状态（闲鱼接口返回什么就推什么，不做过滤）

> **商品图片本期不同步**：云端商品表的 `image_url` 字段保留，但目前不写入。

## 三、业务规则与约束

- 同步方式为**全量拉取**；同步失败后，下次点同步重新全量拉取
- 同步过程中按钮置灰，重复点击不生效
- 同步在后台异步执行，不阻塞界面
- 同步字段不做过滤，闲鱼接口返回什么就推什么：商品 ID、商品标题、商品描述、价格、库存状态
- **商品图片本期不同步**（云端 `image_url` 字段保留、暂不写入）
- 拉取到的全部数据推送到云端后台存储，用于后续消息回复时的商品上下文匹配

## 四、异常与边界场景

| 场景 | 处理要求 |
|------|----------|
| 同步进行中重复点击 | 按钮置灰，重复点击不生效 |
| 同步完成 | 弹出 toast 提示："同步完成，新增 X 个，更新 X 个" |
| 同步失败 | 弹出 toast 提示"同步失败，请重试"，下次点同步重新全量拉取 |
