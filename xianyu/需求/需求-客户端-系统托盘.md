## 一、功能概述（总）

### 1.1 功能定位

系统托盘让应用在关闭主窗口后常驻后台继续监听，并提供托盘级快捷操作（打开主界面、全部停止监听、退出应用），解决"关窗不停服、退出先停监听"的桌面交互问题。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|------|--------|------|
| F1 | 关闭最小化 | 关闭主窗口时，应用最小化到系统托盘，不退出 |
| F2 | 托盘右键菜单 | 打开主界面 / 全部停止监听 / 退出应用 |
| F3 | 双击托盘图标 | 打开主界面 |
| F4 | 退出前清理 | 点「退出应用」时，先自动停止所有正在监听的账号，再退出应用 |

### 1.3 功能边界

- 单个账号的监听启停逻辑归 [需求-客户端-监听控制](需求-客户端-监听控制.md)，本文件只涉及"全部停止监听"的托盘入口
- 启动登录与授权冻结流程归 [需求-客户端-应用框架与启动登录](需求-客户端-应用框架与启动登录.md)
- 运行中异常导致的停止监听归 [需求-客户端-异常与容错](需求-客户端-异常与容错.md)

## 二、功能详述（分）

### 2.1 系统托盘

- 关闭主窗口时，应用最小化到系统托盘，不退出
- 托盘图标右键菜单：
  - 打开主界面
  - 全部停止监听
  - 退出应用
- 双击托盘图标打开主界面
- 点「退出应用」时，先自动停止所有正在监听的账号，再退出应用

## 三、业务规则与约束

- 关闭主窗口 ≠ 退出应用：关闭主窗口时最小化到系统托盘，监听继续运行
- 托盘右键菜单固定三项：打开主界面、全部停止监听、退出应用
- 点「退出应用」必须先自动停止所有正在监听的账号，再退出应用
- 双击托盘图标与右键菜单「打开主界面」等效，均打开主界面

## 四、异常与边界场景

| 场景 | 处理要求 |
|------|----------|
| 用户点击主窗口关闭按钮 | 应用最小化到系统托盘，不退出 |
| 双击托盘图标 | 打开主界面 |
| 托盘右键「全部停止监听」 | 一键停止所有正在监听的账号 |
| 托盘右键「退出应用」 | 先自动停止所有正在监听的账号，再退出应用 |
