# 需求-云端-商品管理

> 来源：《云端需求.md》§3.2 商品管理（内容重组收录，原文件保留未动）
> 关联：[技术方案-云端-商品服务](../技术方案/技术方案-云端-商品服务.md)

## 一、功能概述（总）

### 1.1 功能定位

商品管理是云端管理后台面向运营人员的商品库维护功能：管理由本机「商品同步」上报沉淀到云端的商品数据，并为每个商品维护用于 AI 对话回复的提示词内容，供消息处理时按商品取用。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|---|---|---|
| 1 | 商品列表页 | 展示商品库中的商品，支持按账号筛选，提供编辑、复制提示词到其他商品、删除操作 |
| 2 | 商品编辑（弹窗/抽屉） | 维护商品基本信息与该商品的**系统提示词**，支持「从模板导入」；场景提示词本期不做（见第六节） |
| 3 | 复制提示词到其他商品 | 将当前商品的提示词内容覆盖到选中的目标商品（可多选） |

### 1.3 功能边界

- 商品数据不由本功能从闲鱼拉取；商品数据来源是本机「商品同步」上报，同步规则见[需求-云端-商品同步.md](需求-云端-商品同步.md)。
- 同步只增不删：本机删除的商品云端不自动删除，删除操作在本功能列表页手动完成。
- 提示词模板（系统内置只读预设库）的维护归[需求-云端-提示词模板.md](需求-云端-提示词模板.md)，本功能仅提供「从模板导入」入口。
- 商品基本信息中的库存状态为只读（从同步来），不在编辑弹窗中修改。
- 提示词本期**只维护系统提示词（`system_prompt`）与高级设置（最大回复字数 / 温度 / 最大输出 token）**；议价 / 技术 / 默认三个场景提示词字段在库中保留但**页面不提供输入**，待后续迭代（见第六节）。
- 商品图片本期**不同步**（`image_url` 字段保留但暂不写入），见[需求-云端-商品同步.md](需求-云端-商品同步.md)。

## 二、功能详述（分）

### 2.1 商品列表页

**表格列**：商品标题、所属账号、价格、库存状态、最后同步时间、操作

**筛选**：按账号筛选

**操作按钮**：编辑、复制提示词到其他商品、删除

### 2.2 商品编辑（弹窗/抽屉）

- 基本信息：标题、描述、价格、库存状态（只读，从同步来）
- 系统提示词：textarea，支持变量占位符
- 高级设置：最大回复字数、温度、最大输出 token
- 「从模板导入」按钮：弹出提示词模板列表，选择后填入系统提示词编辑框
- 议价 / 技术 / 默认三个场景提示词**本期不在页面展示、不提供输入**（库字段保留，待后续迭代）

### 2.3 复制提示词到其他商品

- 点击后弹出选择对话框
- 选择目标商品（可多选）
- 确认后将当前商品的提示词内容覆盖到目标商品

## 三、业务规则与约束

1. 商品基本信息中的库存状态为只读，取值来自本机商品同步，不能在后台编辑。
2. 「复制提示词到其他商品」为覆盖式写入：确认后将当前商品的提示词内容覆盖到目标商品。
3. 「从模板导入」是复制填入：导入后商品上的提示词可独立编辑，与模板不再关联（模板机制见[需求-云端-提示词模板.md](需求-云端-提示词模板.md)）。
4. 提示词支持的变量占位符（现行）：`{{item_title}}`、`{{item_desc}}`、`{{item_price}}`、`{{max_reply_length}}`、`{{question}}`（**买家提问回填进提示词**，见[需求-云端-AI对话回复.md](需求-云端-AI对话回复.md) §2.1）。
5. 本期提示词只编辑**系统提示词（`system_prompt`）** 与**高级设置**（最大回复字数 / 温度 / 最大输出 token）；`price_prompt` / `tech_prompt` / `default_prompt` 三个场景提示词字段**留空**，页面不提供输入，待后续迭代。

## 四、异常与边界场景

| 场景 | 处理要求 |
|---|---|
| 同步时商品在云端已存在 | 更新标题/描述/价格/库存状态/同步时间，保留已有提示词（详见[需求-云端-商品同步.md](需求-云端-商品同步.md)） |
| 同步时商品为云端新商品 | 插入完整记录，提示词为空，需在编辑页填写或「从模板导入」 |
| 本机已删除的商品 | 云端不会自动删除，需在本功能列表页手动删除 |
