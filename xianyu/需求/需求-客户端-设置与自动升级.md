## 一、功能概述（总）

### 1.1 功能定位

设置页提供当前应用版本号展示与手动检查更新入口；自动升级覆盖"启动时自动检查 + 设置页手动检查"两种触发方式，按强升/非强升策略弹窗提示，并以整体安装包方式替换 Electron + Python exe，解决客户端版本统一与分发问题。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|------|--------|------|
| F1 | 设置页 | 展示当前应用版本号、「检查更新」按钮，其他设置项后续扩展 |
| F2 | 升级触发方式 | 启动时自动检查 + 设置页手动检查 |
| F3 | 更新提示弹窗 | 展示新版本号与更新说明，按强升/非强升区分按钮 |
| F4 | 升级执行 | 停止所有进程 → 下载新安装包（携带登录 token 鉴权）→ 安装并重启应用 |
| F5 | 升级粒度 | Electron + Python exe 打包成一个安装包，整体替换 |

### 1.3 功能边界

- 安装包下载地址由云端后台提供，云端侧的版本管理归云端
- 升级失败自动回滚为 TODO 暂不实现，见本文件第六节
- 设置项的本地存储机制归 [需求-客户端-安全与本地配置](需求-客户端-安全与本地配置.md)
- 升级期间停止进程与监听的关系：升级流程自行停止所有进程（Electron 主进程 + Python exe）

## 二、功能详述（分）

### 2.1 设置页

- 展示当前应用版本号
- 「检查更新」按钮：手动触发检查更新
- 其他设置项后续扩展

### 2.2 升级触发方式

- **启动时自动检查**：每次打开应用时自动检查是否有新版本；**触发时机在授权校验之前**（登录成功之后，见 [需求-客户端-应用框架与启动登录](需求-客户端-应用框架与启动登录.md) §2.3）；接口不可用不阻断启动
- **手动检查**：设置页点击「检查更新」按钮触发

### 2.3 升级流程

```
1. 检查更新接口返回最新版本信息
2. 对比当前版本：
   - 已是最新 → 提示"当前已是最新版本"
   - 有新版本 → 弹出更新提示弹窗
3. 更新弹窗内容：
   - 新版本号
   - 更新说明
   - 按钮：
     - 强升：只有「立即更新」按钮，无"不升级"选项
     - 非强升：「立即更新」+「以后再说」两个按钮
4. 点击「立即更新」：
   - 停止所有进程（Electron 主进程 + Python exe）
   - 下载新安装包（请求头携带登录 token 鉴权）
   - 安装并重启应用
```

### 2.4 升级粒度

- **整体升级**：Electron + Python exe 打包成一个安装包，整体替换
- 升级期间停止原进程，确保文件可替换

### 2.5 技术方案

- 使用 `electron-updater` 实现自动更新
- 安装包由云端后台提供下载地址
- 安装包下载需登录态：下载请求经自定义请求头携带登录后云端 token（技术方案见 [技术方案-客户端-自动升级](../技术方案/技术方案-客户端-自动升级.md) §2.5）

## 三、业务规则与约束

- 升级触发仅两种：启动时自动检查（每次打开应用时）、设置页手动检查
- 强升版本只有「立即更新」按钮，无"不升级"选项；非强升版本提供「立即更新」+「以后再说」两个按钮
- 更新弹窗必须包含：新版本号、更新说明
- 升级期间停止所有原进程（Electron 主进程 + Python exe），确保文件可替换
- 升级粒度为整体升级：Electron + Python exe 打包成一个安装包，整体替换
- 使用 `electron-updater` 实现自动更新，安装包由云端后台提供下载地址
- 安装包下载需登录态：下载请求经自定义请求头携带登录 token；token 过期时本次升级终止，重新登录后重新检查更新

## 四、异常与边界场景

| 场景 | 处理要求 |
|------|----------|
| 对比后已是最新版本 | 提示"当前已是最新版本" |
| 有新版本且为强升 | 弹出更新提示弹窗，只有「立即更新」按钮，无"不升级"选项 |
| 有新版本且为非强升 | 弹出更新提示弹窗，「立即更新」+「以后再说」两个按钮 |
| 点击「立即更新」 | 停止所有进程（Electron 主进程 + Python exe）→ 下载新安装包（携带登录 token 鉴权）→ 安装并重启应用 |
| 安装包下载 401（未登录 / token 过期） | 终止本次升级，复用 401 处理（删本地 token、跳转登录页）；重新登录后重新检查更新 |
| 升级后启动失败 | 自动回滚到旧版本（TODO，暂不实现，见第六节） |
