# 需求-客户端-日志

> 来源：《客户端需求.md》§十一 日志页、§十七 日志轮转（内容重组收录，原文件保留未动）
> 关联：[技术方案-客户端-日志系统](../技术方案/技术方案-客户端-日志系统.md)

## 一、功能概述（总）

### 1.1 功能定位

日志功能提供本地 Python 服务运行情况的可观测窗口：界面侧提供日志查看页（级别筛选、清空、导出），文件侧提供日志自动轮转（单文件大小上限 + 历史文件数量上限），解决"本地运行过程可追溯、日志不无限膨胀"的问题。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|------|--------|------|
| F1 | 日志页展示 | 展示本地 Python 服务的运行日志 |
| F2 | 日志内容 | 系统运行日志 + 消息收发记录（收到买家消息、AI 回复内容、发送结果） |
| F3 | 级别筛选 | 支持按级别筛选（info/warn/error） |
| F4 | 清空与导出 | 支持清空、导出 |
| F5 | 日志文件轮转 | 单文件 10MB 上限，最多保留 5 个历史日志文件，超限自动删除最旧文件 |

### 1.3 功能边界

- 日志由本地 Python 服务产生，日志系统的实现归 [技术方案-客户端-日志系统](../技术方案/技术方案-客户端-日志系统.md)
- 消息收发记录对应的业务流程归 [需求-客户端-消息自动回复](需求-客户端-消息自动回复.md)
- 云端侧的日志与监控归云端，不在本文件范围

## 二、功能详述（分）

### 2.1 日志页

- 展示本地 Python 服务的运行日志
- 日志内容包含：系统运行日志 + 消息收发记录（收到买家消息、AI 回复内容、发送结果）
- 支持按级别筛选（info/warn/error）
- 支持清空、导出

### 2.2 日志轮转

- 本地日志文件自动轮转
- 单文件大小上限：10MB
- 最多保留 5 个历史日志文件
- 超过上限自动删除最旧的日志文件

## 三、业务规则与约束

- 日志内容包含两类：系统运行日志、消息收发记录（收到买家消息、AI 回复内容、发送结果）
- 筛选级别枚举：info / warn / error
- 单文件大小上限 10MB；最多保留 5 个历史日志文件；超过上限自动删除最旧的日志文件
- 轮转为自动执行，无需用户干预

## 四、异常与边界场景

| 场景 | 处理要求 |
|------|----------|
| 单个日志文件达到 10MB | 自动轮转，产生新日志文件 |
| 历史日志文件超过 5 个 | 自动删除最旧的日志文件 |
| 需要离线排查问题 | 支持导出日志 |
| 日志量大影响查看 | 支持按级别（info/warn/error）筛选、支持清空 |
