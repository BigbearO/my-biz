# 需求-客户端-消息自动回复

> 来源：《客户端需求.md》§八 消息处理流程、§十六 消息合并滑动窗口（内容重组收录，原文件保留未动）
> 关联：[技术方案-客户端-消息处理流水线](../技术方案/技术方案-客户端-消息处理流水线.md)

## 一、功能概述（总）

### 1.1 功能定位

消息自动回复是客户端的核心业务链路：本机监听到买家消息后，经消息去重、字段提取、图片处理、滑动窗口合并、请求前随机延迟，推送到云端生成 AI 回复，收到回复后立即调用闲鱼接口发送，实现无人值守的自动应答。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|------|--------|------|
| F1 | 消息接收与去重 | 本机 WebSocket 收到事件后，按 message_id 去重，重复消息直接丢弃 |
| F2 | 字段提取 | 提取消息 ID、商品 ID、买家 ID、会话 ID、消息内容、消息类型 |
| F3 | 图片消息处理 | 图片下载转 PNG、上传云端换 URL 后随消息上报（详见图片消息功能点） |
| F4 | 滑动窗口合并 | 同一买家 + 同一商品，5 秒内的多条消息合并成一条再提交云端 |
| F5 | 请求前随机延迟 | 在请求云端之前，本机等待 1-2 秒随机延迟，模拟真人节奏 |
| F6 | 云端调用与发送 | 携带全部字段 + 登录 token 推送云端生成回复，收到后立即发送，不再额外延迟 |

### 1.3 功能边界

- 图片消息的下载、转 PNG、上传换 URL 的具体步骤归 [需求-客户端-图片消息](需求-客户端-图片消息.md)，本文件只保留其在整体流程中的位置
- 商品数据的来源（全量同步到云端）归 [需求-客户端-商品同步](需求-客户端-商品同步.md)
- 云端侧的商品匹配、提示词加载、大模型调用与对话历史维护归云端，见 [技术方案-云端-对话服务-AI回复编排](../技术方案/技术方案-云端-对话服务-AI回复编排.md)
- 消息发送失败重试、云端接口不可用重试归 [需求-客户端-异常与容错](需求-客户端-异常与容错.md)
- 客户端不维护对话历史，由云端维护

## 二、功能详述（分）

### 2.1 消息处理全流程

```
买家发送消息
    ↓
本机 WebSocket 收到事件
    ↓
消息去重：按 message_id 去重，重复消息直接丢弃
    ↓
提取字段：
  - 消息 ID（message_id）
  - 商品 ID（item_id）
  - 买家 ID（buyer_id）
  - 会话 ID（session_id）
  - 消息内容（message）
  - 消息类型（text / image）
    ↓
图片消息处理：→ 详见 [需求-客户端-图片消息](需求-客户端-图片消息.md)（本机下载转 PNG、上传云端换取 URL 后随消息上报；文本消息直接上报）
    ↓
滑动窗口合并：
  - 同一买家 + 同一商品，5 秒内的多条消息合并
    ↓
随机延迟（★ 在请求云端之前）：
  - 本机等待 1-2 秒随机延迟，模拟真人"看到消息 → 想一下 → 再回复"的节奏
    ↓
推送到云端管理后台（携带上述全部字段 + 登录 token）
    ↓
云端处理：
  1. 根据商品 ID 匹配商品库
  2. 加载商品上的提示词
  3. 用 item_id + buyer_id 作为对话 ID，调用大模型生成回复（云端维护对话历史）
    ↓
返回回复内容到本机
    ↓
立即调用闲鱼接口发送消息（不再额外延迟）
```

> 说明：无人工审核环节，AI 生成后直接下发发送。
>
> **商品不存在处理**：如果云端找不到对应商品，返回错误码，本机不发送、不回复。
>
> **对话历史**：客户端不维护对话历史，由云端用「商品 ID + 买家 ID」作为对话 ID 去维护上下文。

### 2.2 消息合并滑动窗口

- 同一买家 + 同一商品，5 秒内的多条消息合并成一条，再提交到云端 AI 对话
- 滑动窗口时长为本地配置项，默认 5 秒，可修改
- 合并规则：按时间顺序拼接消息内容，保留原始消息列表
- 图文合并：同一窗口内的文字和图片消息合并为一条，一起传给多模态模型
- **请求云端之前**，本机等待 1-2 秒随机延迟（模拟真人回复节奏）；收到回复后立即发送，不再延迟

## 三、业务规则与约束

- 去重规则：按 message_id 去重，重复消息直接丢弃、不重复上报
- 上报必须携带：全部提取字段（消息 ID、商品 ID、买家 ID、会话 ID、消息内容、消息类型）+ 登录 token；消息路由依赖商品 ID 和买家 ID
- 滑动窗口时长为本地配置项，默认 5 秒，可修改；合并规则为按时间顺序拼接消息内容，保留原始消息列表
- 随机延迟时机：★ 必须在**请求云端之前**，本机等待 1-2 秒随机延迟；收到回复后**立即发送，不再额外延迟**
- 无人工审核环节，AI 生成后直接下发发送
- 对话 ID = item_id + buyer_id，对话历史由云端维护，客户端不维护

## 四、异常与边界场景

| 场景 | 处理要求 |
|------|----------|
| 收到重复消息（相同 message_id） | 直接丢弃，不重复上报 |
| 云端找不到对应商品 | 云端返回错误码，本机不发送、不回复 |
| 消息类型为 image | 进入图片消息处理流程，见 [需求-客户端-图片消息](需求-客户端-图片消息.md) |
| 请求云端接口失败 | 自动重试，见 [需求-客户端-异常与容错](需求-客户端-异常与容错.md) |
| 回复下发后的发送失败 | 自动重试，见 [需求-客户端-异常与容错](需求-客户端-异常与容错.md) |

## 五、验收标准

| 编号 | 验收项 | 判定标准 |
|------|--------|----------|
| A9 | 消息路由 | 消息上报时携带商品 ID 和买家 ID，云端正确匹配 |
| A23 | 消息合并滑动窗口 | 同一买家同一商品 5s 内消息合并后再提交云端 |
| A29 | 请求前随机延迟 | 请求云端接口**之前**本机等待 1-2 秒随机延迟；收到回复后立即发送，不再延迟 |
| A30 | 商品不存在不回复 | 云端找不到商品时返回错误码，本机不发送不回复 |
| A31 | 消息去重 | 按 message_id 去重，重复消息不重复上报 |
