## 一、功能概述（总）

### 1.1 功能定位

云端管理后台是面向运营人员的 Web 管理端（plus-ui），承载 AI 对话核心业务逻辑的配置与展示：商品管理、提示词管理、模型配置、版本管理、账号查看，以及作为首页的仪表盘统计。仪表盘为纯展示页面，仅两个数字卡片。

### 1.2 子功能清单

| 编号 | 子功能 | 说明 |
|---|---|---|
| 1 | 仪表盘 | 纯展示，两个数字卡片：账号数、商品数 |
| 2 | 后台页面菜单（闲鱼管理） | 6 个页面：仪表盘、账号管理、商品管理、提示词模板（只读）、模型管理、版本管理 |

### 1.3 功能边界

- 云端管理后台**不包含登录页、会话记录页、设备管理页**（基础脚手架已有，会话记录直接在闲鱼端查看）。
- 仪表盘**不做实时数据、不做趋势图、不做消息统计**。
- 消息处理、授权校验属于云端接口能力，无独立后台页面（见[需求-云端-AI对话回复.md](需求-云端-AI对话回复.md)、[需求-云端-登录与授权校验.md](需求-云端-登录与授权校验.md)）。
- 各页面的详细功能见 §2.2 页面清单中对应功能点文档；目录结构、接口前缀等技术细节见[技术方案-云端-管理后台前端](../技术方案/技术方案-云端-管理后台前端.md)。

## 二、功能详述（分）

### 2.1 仪表盘

**功能**：纯展示，两个数字卡片
- 账号数：goodfish 账号总记录数
- 商品数：商品库总记录数

**说明**：不做实时数据、不做趋势图、不做消息统计。

### 2.2 后台页面清单（菜单结构）

```
闲鱼管理
├── 仪表盘
├── 账号管理
├── 商品管理
├── 提示词模板（只读）
├── 模型管理
└── 版本管理
```

> **提示词模板页面为只读**：数据来自商品服务的 Spring 配置文件（`goodfish-prompt-templates.yml`），仅支持「查看」与「导入到商品」，**不提供新增 / 编辑 / 删除**。

| 页面 | 展示 / 维护内容 | 详细需求 |
|---|---|---|
| 仪表盘 | 账号数、商品数两个数字卡片 | 本文件 §2.1 |
| 账号管理 | goodfish 账号信息（闲鱼 ID、昵称、备注、最后活跃时间） | [需求-云端-账号管理.md](需求-云端-账号管理.md) |
| 商品管理 | 商品列表、商品编辑（含提示词编辑）、复制提示词到其他商品 | [需求-云端-商品管理.md](需求-云端-商品管理.md) |
| 提示词模板（只读） | 系统内置模板列表（模板编码、模板名称），仅「导入到商品」 | [需求-云端-提示词模板.md](需求-云端-提示词模板.md) |
| 模型管理 | 供应商管理、模型管理、测试连接 | [需求-云端-模型管理.md](需求-云端-模型管理.md) |
| 版本管理 | 版本列表、发布新版本、检查更新接口 | [需求-云端-版本管理与更新检查.md](需求-云端-版本管理与更新检查.md) |

## 三、业务规则与约束

1. 云端管理后台负责 AI 对话的核心业务逻辑：商品管理、提示词管理、模型配置、消息处理、授权校验。
2. 仪表盘为纯静态展示：账号数取 goodfish 账号总记录数，商品数取商品库总记录数；不做实时数据、不做趋势图、不做消息统计。
3. 后台页面以上述菜单结构为准，仅 6 项；不提供会话记录页、设备管理页。

## 四、异常与边界场景

| 场景 | 处理要求 |
|---|---|
| 需要查看会话记录 | 云端不提供会话记录页，直接在闲鱼端查看 |
| 需要实时数据 / 趋势图 / 消息统计 | 仪表盘不提供，仅账号数、商品数两个静态数字卡片 |
