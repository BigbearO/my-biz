## 一、功能与职责（总）

### 1.1 功能定位

汇总云端对话服务（goodfish-ai-service）在各环节的异常处理与降级策略，覆盖：启动期强依赖（Nacos、数据库）、配置热更新、下游基础服务 gRPC 调用、大模型调用、幂等与缓存、进程生命周期。

### 1.2 职责边界 / 范围

- 本文件聚焦**对话服务自身**的异常策略（大模型调用失败 / 下游 gRPC 失败 / 缓存失效等的处理与降级）。
- 业务**错误码映射**（40401 / 40402 / 50001 / 50002 / 50301 等）见《[技术方案-云端-gRPC契约](技术方案-云端-gRPC契约.md)》，本文不重复。
- **gRPC 降级矩阵**（发现库层面的实例摘除/降级行为）见《[技术方案-云端-gRPC发现库xxs-nacos-grpc](技术方案-云端-gRPC发现库xxs-nacos-grpc.md)》，本文不重复。
- 客户端侧的异常与容错见《[技术方案-客户端-云端调用与容错](技术方案-客户端-云端调用与容错.md)》。

### 1.3 与其他模块的关系

| 相关模块 | 关系 |
|---|---|
| 服务注册与发现 / Nacos | 启动注册、配置中心强依赖、ephemeral 实例自动摘除均依赖 Nacos 行为 |
| 商品服务 / 模型服务 | 下游 gRPC 依赖：超时、重试与失败码由本文件策略约束 |
| 对话服务-AI回复编排 | 编排链路中各步失败即按本文件策略返回对应错误码 |
| 对话服务-接口与幂等 | 幂等占位 / Redis 降级策略与幂等实现直接相关 |

## 二、逻辑实现（分）

### 2.1 总体设计

异常策略按阶段划分：

- **启动期**：对强依赖（配置中心、数据库）失败快速失败、不注册实例，避免半启动节点放大故障。
- **运行期配置**：热更新失败保留旧配置，监听回调异常不影响主流程。
- **下游调用**：按依赖区分错误码（商品服务问题不外溢为模型问题）；命中缓存时下游失败不影响回复。
- **大模型调用**：超时 + 有限重试，仍失败返回统一错误码。
- **幂等**：Redis 不可用时可用性优先，降级跳过幂等。
- **进程退出**：ephemeral 实例随连接断开被 Nacos 自动摘除，网关停止转发。

### 2.2 异常场景与处理策略

| 异常场景 | 处理方案 |
|---|---|
| **Nacos 连接失败（启动时）** | 重试 3 次（间隔 2s，容忍 Nacos 滚动重启）→ 仍失败则拒绝启动（配置中心是强依赖，半启动的服务注册上去只会放大故障） |
| **Nacos 配置拉取失败（运行中重连后）** | 继续使用内存中最后一次有效配置；SDK 按 `cache_dir` 快照兜底 |
| **注册 IP 探测失败（无默认路由）** | 退化为主机名解析；仍失败则报错退出，**绝不允许以 `0.0.0.0` 注册** |
| **多 worker 部署** | 禁止（`workers=1`）；否则任一 worker 退出会摘除整个实例，导致网关 503 |
| **配置监听回调异常** | 捕获并记日志，不影响主流程；回调内只做"解析+原子替换"，失败保留旧配置 |
| **配置内容非法（解析失败）** | 启动时直接失败；热更新时保留旧配置 + 告警日志 |
| **下游基础服务无可用 gRPC 实例** | 订阅缓存为空（商品服务或模型服务）→ 返回 50301，客户端进入只监听模式 |
| **商品服务 gRPC 超时 / 失败** | 超时 3s，重试 1 次；仍失败返回 **50301**（不外溢为 50001，避免客户端误判为模型问题） |
| **商品服务返回 NOT_FOUND** | 返回 40401，客户端不回复（A30） |
| **商品提示词未配置（`system_prompt` 为空）** ★ | 返回 **40402**，不调大模型，客户端不回复 |
| **模型服务 gRPC 超时 / 失败** | 命中缓存时不受影响；缓存未命中且调用失败 → 50301 |
| **无启用模型（`GetEnabledModel` 返回 NOT_FOUND）** ★ | 返回 **50002**，不调大模型，客户端不回复、不重试 |
| **身份透传缺失 / 非法** | 按项目统一规范处理：白名单场景允许空身份；缺失必需身份时返回 `UNAUTHENTICATED`，记 WARN（不引入内部令牌） |
| **本服务 gRPC 服务端异常** | 拦截器统一映射为 gRPC status；未捕获异常返回 `INTERNAL`，**不泄漏堆栈** |
| **大模型调用超时/失败** | 超时 30s，重试 2 次间隔 2s，仍失败返回 50001 |
| **数据库连接失败** | 启动时重试 3 次，仍失败则服务启动失败（不注册） |
| **对话历史写入失败** | 不影响回复返回，异步重试写入并记 ERROR；**可靠性方案见《[客户端监听.md](../客户端监听.md)》第五章 TODO「历史可靠写入」**（历史改为长期保留后需保证不丢） |
| **重复 request_id 请求** ★ | 返回 Redis 中缓存的响应（幂等命中），不重复生成、不重复落库 |
| **处理中途异常** ★ | 释放幂等占位（DEL），避免客户端被"处理中"卡到 TTL 到期 |
| **Redis 不可用（幂等降级）** ★ | 跳过幂等检查并记 WARN；可用性优先，接受低频重复回复 |
| **进程崩溃/SIGKILL** | ephemeral 实例随 gRPC 连接断开被 Nacos 自动摘除，网关不再转发 |
