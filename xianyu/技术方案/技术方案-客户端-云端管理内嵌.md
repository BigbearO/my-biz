## 一、功能与职责（总）

### 1.1 功能定位

Electron 渲染层通过**内嵌 WebView 打开云端后台地址**（`cloud_backend_url`，打包写死），用户不离开客户端即可进入商品 / 提示词 / 模型的管理后台。

**plus-ui 是独立部署的云端应用，与客户端无耦合、客户端不做任何注入或改造。** 本文件只定义 **WebView 容器侧**的技术方案：加载、会话隔离与加载失败兜底。

**架构边界**：

| | 「云端管理」页 | 客户端本地页（账号管理 / 日志 / 设置） |
|---|---|---|
| 页面来源 | 内嵌 WebView 加载**云端后台地址** | Electron 渲染层**自研页面** |
| 后端 | 云端的 plus-ui + 云端服务（**plus-ui 独立存在、自有登录与 token 存储**） | **内嵌 Python 本地服务**（`http://127.0.0.1:{port}/api`，SQLite 存储） |
| 登录态 | **由 plus-ui 自身处理**（客户端不注入、不干预） | 本地 token（config 表） |

> 客户端**不内嵌 plus-ui 的前端工程**，也**不要求 plus-ui 做任何配合改造**：WebView 只是指向其云端部署地址；后台的页面、登录、会话、401 跳转全部由 plus-ui 自行处理。
>
> **各自登录**：客户端自身的登录（Electron 登录页，实现参考 plus-ui / RuoYi）与**云端后台的登录是两套独立登录态**，互不通用；进入「云端管理」时后台未登录，由 plus-ui 自行引导登录，客户端不介入。

### 1.2 职责边界

| 负责 | 不负责 |
|---|---|
| WebView 创建与加载（后台地址打包写死，不存本地配置） | 后台内部页面、登录流程、接口实现（plus-ui 与云端服务，归云端文档） |
| WebView 专属 session partition（与应用默认会话隔离） | 后台登录态与 token 的存储/刷新（由 plus-ui 自身处理） |
| 加载失败兜底（提示 + 重试） | 后台业务错误的展示（由后台页面自行展示） |

### 1.3 与其他模块的关系

| 对象 | 方向 | 交互方式 |
|---|---|---|
| 云端后台（plus-ui） | 下游 | WebView 加载其公网地址；HTTP 请求由 plus-ui 自身携带其登录态，**客户端不注入请求头** |
| Electron 渲染层 | 上游 | 菜单点击进入/切换；加载失败时展示兜底提示 |
| 本地 config 表 | — | **不参与**：本页登录态由 plus-ui 自理，不读本地 `auth_token` |

## 二、逻辑实现（分）

### 2.1 总体设计

```
渲染层点击「云端管理」菜单
    ↓
主进程获取/创建 WebView（专属 session partition: persist:admin-webview）
    ↓
加载云端后台地址（打包写死）
    ↓
后台所有请求由 plus-ui 自身处理（含其登录态与 401 跳转）
    ↓
加载失败 → WebView 区域显示"云端管理加载失败"提示 + 重试按钮
```

### 2.2 容器侧约定

- WebView 使用**专属 session partition**（`persist:admin-webview`），与应用默认会话隔离，互不影响；
- **不做请求头注入、不拦截响应**：不加 `webRequest` 钩子，后台登录态与 401 全部由 plus-ui 自行处理；
- 后台地址（`cloud_backend_url`）为**打包写死的常量**（见 [需求-客户端-安全与本地配置](../需求/需求-客户端-安全与本地配置.md)），不落本地配置表、可由 WebView 直接加载。

## 三、异常与容错

| 异常场景 | 处理策略 |
|---|---|
| 后台地址不可达 / WebView 加载失败 | WebView 区域显示"云端管理加载失败"提示 + 重试按钮，不影响其他页面功能 |
| 后台内登录态过期（401） | **由 plus-ui 自身处理**（跳其登录页），客户端不介入 |
| WebView 内管理操作报业务错误 | 由后台页面自行展示 |

## 四、配置项

| 配置项 | 值 | 说明 |
|---|---|---|
| 云端后台地址 | 打包写死 | WebView 加载地址（不存本地配置，见 [需求-客户端-安全与本地配置](../需求/需求-客户端-安全与本地配置.md)） |
| session partition | `persist:admin-webview` | WebView 专属会话，与应用默认会话隔离 |
