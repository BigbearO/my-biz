## 一、功能与职责（总）

### 1.1 功能定位

定义客户端代码的目录组织与打包交付方式。客户端代码分三部分：Electron 主进程、Vue 渲染层、Python 本地服务。打包分两段：Python 用 PyInstaller 打包为可执行产物，Electron 用 electron-builder 打成 Windows NSIS 安装包并把 Python 产物作为 extraResource 一并打入；升级时 Electron + Python 整体升级（见 [技术方案-客户端-自动升级](技术方案-客户端-自动升级.md)）。

### 1.2 职责边界

| 负责 | 不负责 |
|---|---|
| 三层目录结构约定与各层代码归属 | 各模块业务逻辑设计（见同目录各功能点文档） |
| PyInstaller / electron-builder 打包方式、输出位置、依赖清单 | 升级策略与强升/非强升交互（见 [技术方案-客户端-自动升级](技术方案-客户端-自动升级.md)） |
| 数据目录约定（`%APPDATA%/goodfish`，不写安装目录） | Python 进程的启动/守护与失败重试（见 [技术方案-客户端-本地服务进程管理](技术方案-客户端-本地服务进程管理.md)） |
| AGPL 合规文件随包携带（LICENSE 副本 + `xianyu/UPSTREAM.md`） | 协议层本身的实现（见 [技术方案-客户端-闲鱼协议层](技术方案-客户端-闲鱼协议层.md)） |

### 1.3 与其他模块的关系

| 对象 | 方向 | 交互方式 |
|---|---|---|
| Electron 主进程（python-manager.js） | 下游 | 打包产物 `electron/resources/python/` 中的 exe 被主进程 child_process 拉起 |
| 自动升级（electron-updater） | 下游 | electron-builder 产出的 NSIS 安装包是整体升级的载体 |
| 协议层与动态导入依赖 | 下游 | `xianyu/` 包与 `uvicorn`/`sqlalchemy`/`Pillow` 的动态导入需在 `.spec` 显式声明 `hiddenimports` |

## 二、逻辑实现（分）

### 2.1 项目目录结构

项目代码位于：`E:\project\my-biz\xianyu\client\`

```
xianyu-client/
├── electron/                 # Electron 主进程代码
│   ├── main.js                # 主进程入口
│   ├── tray.js                # 系统托盘
│   ├── updater.js             # 自动升级
│   └── python-manager.js      # Python 进程管理
├── src/                       # Vue 渲染层代码
│   ├── main.js                # 渲染层入口
│   ├── App.vue
│   ├── router/                 # 路由
│   ├── views/                 # 页面
│   │   ├── Login.vue           # 登录页
│   │   ├── AccountList.vue     # 账号管理页
│   │   ├── （无 CloudAdmin.vue：云端管理页已裁定取消）
│   │   ├── （无 Logs.vue：日志页已取消，日志只落本地文件）
│   │   └── Settings.vue        # 设置页
│   ├── api/                   # 本地 API 调用封装
│   ├── components/             # 公共组件
│   └── assets/                 # 静态资源
├── python/                    # Python 本地服务代码（内部结构以 [技术方案-客户端-总体架构](技术方案-客户端-总体架构.md) §2.2.1 为准）
│   ├── main.py                # 进程入口：端口协商 → uvicorn 启动
│   ├── app.py                 # FastAPI 工厂 + lifespan
│   ├── core/                  # 配置加载 / 加密 / 日志 / 事件总线 / 状态机
│   ├── db/                    # SQLAlchemy 模型 / 会话 / 单表 CRUD
│   ├── xianyu/                # 闲鱼协议层（复用实现 + 抽象接口，见 技术方案-客户端-闲鱼协议层）
│   ├── services/              # 业务逻辑
│   │   ├── account_service.py  # 账号增删查 + 去重
│   │   ├── listen_manager.py   # 监听上限 + 启停编排
│   │   ├── message_pipeline.py # 消息处理流水线（过滤/去重/窗口/锁）
│   │   ├── image_service.py    # 图片处理（下载、转 PNG、上传拿 URL、降级占位）
│   │   ├── item_sync_service.py # 商品同步
│   │   └── cloud_client.py     # 云端 API 调用
│   ├── api/                   # 本地 HTTP 路由
│   │   ├── account.py          # 账号管理
│   │   ├── sync.py             # 商品同步
│   │   ├── system.py           # 系统信息
│   │   └── logs.py             # 日志
│   └── schemas/               # Pydantic 模型
├── package.json
├── electron-builder.yml       # 打包配置
└── pyinstaller.spec           # Python 打包配置
```

### 2.2 Python 打包

- 使用 PyInstaller 打包（初版方案为单 exe，现行采用 **onedir**，见下表）；
- 包含所有依赖（FastAPI、SQLAlchemy、Pillow 等）；
- 输出到 `electron/resources/` 目录，由 electron-builder 作为 `extraResources` 打入安装包。

| 项 | 方案 |
|---|---|
| **打包方式** | PyInstaller **onedir**（非 onefile）：启动快、无自解压临时目录、协议层依赖更易打进 |
| **输出位置** | `electron/resources/python/`，由 electron-builder 作为 `extraResources` 打入安装包 |
| **隐藏导入** | 协议层与 `uvicorn`/`sqlalchemy`/`Pillow` 的动态导入需在 `.spec` 显式声明 `hiddenimports` |
| **数据目录** | 一律使用 `%APPDATA%/goodfish`（配置/日志/密钥/DB），**不写安装目录**（Program Files 无写权限） |
| **依赖清单** | `fastapi`、`uvicorn[standard]`、`aiohttp`（协议层 WS，复用实现自带）、`httpx`、`sqlalchemy[asyncio]`+`aiosqlite`、`alembic`、`pydantic`、`loguru`、`Pillow`、`cryptography`、`pywin32`（DPAPI） |
| **不引入的依赖** ★ | `playwright` / `patchright` / `opencv-python-headless`（上游用于扫码登录与过滑块，本期不做，**可省约 300MB 浏览器内核**）；`redis`（本地单机自实现 token 缓存）；`protobuf` / `blackboxprotobuf`（复用实现不解 protobuf） |
| **无外部运行时** ★ | 协议层为**纯 Python**（已核实无 execjs / Node），**无需打包 Node**，安装包体积不受协议层影响 |
| **License 文件** ★ | 随包附带上游 AGPL-3.0 LICENSE 副本与 `xianyu/UPSTREAM.md`（仓库地址 + commit SHA），满足 AGPL 署名与溯源义务 |
| **版本固定** | 全部依赖钉死版本，保证 PyInstaller 产物可复现 |

### 2.3 Electron 打包

- 使用 electron-builder 打包成安装包；
- 把 Python exe 作为 extraResource 打进去；
- 输出 NSIS 安装包（Windows）；
- 整体升级：Electron + Python 一起升级（升级流程见 [技术方案-客户端-自动升级](技术方案-客户端-自动升级.md)）。
