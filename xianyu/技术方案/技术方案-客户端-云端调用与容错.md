# 技术方案-客户端-云端调用与容错

> 来源：[《客户端监听.md》](../客户端监听.md) §4.1 客户端异常处理；[《客户端技术方案.md》](../客户端技术方案.md) §6.4 云端客户端 cloud_client（内容重组收录，原文件保留未动）
> 关联：[需求-客户端-异常与容错](../需求/需求-客户端-异常与容错.md)

## 一、功能与职责（总）

### 1.1 功能定位

CloudClient（`services/cloud_client.py`）封装**所有云端 API 调用**，是客户端访问云端（经网关）的唯一出口：token 注入、统一重试、401/403 统一处理、"云端不可用"状态维护。消息流水线的 AI 请求、商品上报、授权校验等都经它发出。

### 1.2 职责边界

| 负责 | 不负责 |
|---|---|
| 封装所有云端 API 调用，自动带上 auth_token | 业务分支决策（40401/50001 等响应码的业务语义由调用方流水线处理） |
| 请求失败重试（3 次，间隔 2-3 秒随机） | 云端服务自身的容错（见 [技术方案-云端-异常与容错](技术方案-云端-异常与容错.md)） |
| 401 统一处理：删除本地 token + 经事件通知渲染层跳登录页 | 登录页 UI 与重新登录（用户手动输入账号密码，不自动重登） |
| 连续失败超过 3 次触发"云端不可用"状态，恢复后自动继续 | 闲鱼侧异常（协议/WS 层，见 [技术方案-客户端-闲鱼协议层](技术方案-客户端-闲鱼协议层.md)） |
| 幂等键 `request_id` 的生成与携带（云端按此去重） | 对话历史的存储（云端侧职责） |

### 1.3 与其他模块的关系

| 对象 | 方向 | 交互方式 |
|---|---|---|
| 消息处理流水线 | 上游 | `/api/ai/reply`（带 `Authorization: Bearer <token>` 与幂等 `request_id`）、`/api/ai/image` |
| 商品同步 | 上游 | 商品数据上报云端 |
| Electron 渲染层 | 下游 | 401 → `/api/system/status` 返回登录态过期标记，渲染层轮询到后跳转登录页；云端不可用 → status 置"不可用"，渲染层轮询感知 |
| 云端网关 / 对话服务 | 下游 | HTTP 调用（AI 回复编排见 [技术方案-云端-对话服务-AI回复编排](技术方案-云端-对话服务-AI回复编排.md)） |
| 本地存储 | 下游 | auth_token 落 config 表；删除 token 即清空该配置 |

## 二、逻辑实现（分）

### 2.1 总体设计

- 封装所有云端 API 调用；
- 自动带上 auth_token；
- 401 自动跳登录页（通过事件通知渲染层）；
- 请求失败重试 3 次，间隔 2-3 秒随机；
- 连续失败超过 3 次触发"云端不可用"状态。

### 2.2 重试与"云端不可用"状态

- 调云端接口失败时**自动重试 3 次，间隔 2-3 秒随机**；
- 3 次都失败 → 弹窗提示"**云端服务暂不可用，仅监听不回复**"，进入"仅监听不回复"模式（A21）：监听与消息入列不中断，只是不发起 AI 回复；
- **连续失败超过 3 次**触发"云端不可用"状态，经 `/api/system/status` 的云端连通状态字段暴露（渲染层轮询感知）；
- **云端恢复后自动继续**正常流程，不丢消息。

### 2.3 401 / 403 统一处理

| 响应 | 处理 |
|---|---|
| **401 / 40101**（登录 token 过期） | **删除本地 token** + `/api/system/status` 返回登录态过期标记，渲染层轮询到后跳转登录页；**不自动重登**（需用户手动输入账号密码）；监听保持运行（A27） |
| **403 / 40301**（授权过期/未授权） | **删除本地 token** + 停止所有监听 + 弹窗"授权已过期" + **冻结应用，只允许退出**（A42） |

## 五、异常与容错

客户端异常处理总表（[《客户端监听.md》](../客户端监听.md) §4.1）：

| 异常场景 | 处理方案 |
|---|---|
| **本地服务启动失败** | Electron 重试 2 次（间隔 2s），仍失败弹窗"本地服务启动失败，请联系管理员"并退出 |
| **WebSocket 断线** | 重连 3 次（5s/10s/15s），仍失败标记"连接断开"（A17） |
| **Cookie 失效** | 停止监听 + 标记失效 + 弹窗提示，不提供重新输入 |
| **云端不可用** | 重试 3 次（2-3s 随机间隔），仍失败弹窗提示，只监听不回复；恢复后自动继续（A21） |
| **商品不存在** | 云端返回 40401，不回复（A30） |
| **大模型调用失败** | 云端返回 50001，不回复（TODO：降级策略） |
| **消息发送失败** | 重试 3 次（2-3s 随机），仍失败仅记本地日志，不上报云端（A19，send-result 上报已移除） |
| **登录 token 过期** | 云端返回 401 → **删除本地 token** + status 返回过期标记，渲染层轮询到后跳转登录页，不自动重登；监听保持运行（A27，见《客户端监听.md》§1.5.3） |
| **授权过期 / 未授权** ★ | 云端返回 403（`40301`）→ **删除本地 token** + 停止所有监听 + 弹窗"授权已过期" + 冻结应用，只允许退出（A42，见《客户端监听.md》§1.5.4） |
| **退出应用** | 先停止所有监听，再退出进程（A38） |
| **重启恢复** | 重启后不自动恢复监听（A25） |
| **图片下载 / 上传失败** ★ | 该图替换为 `[图片]` 占位，仅上报文本，不阻断流程（客户端下载闲鱼图片或上传后端失败时降级） |
| **端口握手超时** ★ | Electron 依次回退：`runtime.json` → 端口段探测 → 弹窗"本地服务启动失败" |
| **主密钥解密失败** ★ | 提示"凭证无法解密，请重新录入 Cookie"，**不静默清空**用户数据 |
| **收到自己发出的消息回推** ★ | 由"自身消息过滤"直接丢弃（DEBUG 级记录），不进入 AI 流程 |
| **token 失效（code=400）** ★ | 复用实现自动重连并换 token（代次 + 互斥锁保证并发只重连一次）；外层记一次重连计数 |
| **IM 流控（400600001）** ★ | 复用实现自动退避 `(n+1)*2` 秒、最多 3 次；连续失败则上报状态并延长退避 |
| **推送解密失败** ★ | 记录脱敏后的原始报文以便跟进协议变更；丢弃该帧但**不中断连接**，累计失败超阈值告警 |
| **发送被安全拦截** ★ | 解析 `reason` / `moreInfo`（如 `CSI_FORBID||安全拦截`）→ 记日志 + 上报云端，**不重试**（避免连续触发风控） |

> 各异常域的展开说明：进程启动/崩溃见 [技术方案-客户端-本地服务进程管理](技术方案-客户端-本地服务进程管理.md)；WS 连接见 [技术方案-客户端-WebSocket监听](技术方案-客户端-WebSocket监听.md)；消息流水线响应码分支见 [技术方案-客户端-消息处理流水线](技术方案-客户端-消息处理流水线.md) §五。
