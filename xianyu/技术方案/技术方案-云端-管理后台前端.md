## 一、功能与职责（总）

### 1.1 功能定位

管理后台前端基于 plus-ui 实现：在 plus-ui 前端项目中新增页面，代码路径：`E:\project\ruoyi\plus-ui\src\views\goodfish`。

### 1.2 职责边界 / 范围

- 前端只负责页面呈现与接口调用，业务数据全部来自后端接口。
- 前端调用的接口按 §3.5 裁定分两类：**跨域聚合走 admin BFF**、**单域 CRUD 直连基础服务**（见 2.3）。
- 提示词模板页面为**只读**页面（见 2.2）。

### 1.3 与其他模块的关系

| 相关模块 | 关系 |
|---|---|
| `ruoyi-goodfish-admin`（admin BFF） | 仪表盘、商品列表两个跨域聚合页面的数据来源 |
| 商品服务 | 商品管理编辑/删除/复制提示词、提示词模板的直连数据来源 |
| 客户端元数据服务 | 账号管理、版本管理的直连数据来源 |
| 模型服务 | 模型管理（供应商/模型）的直连数据来源 |
| RuoYi-Cloud-Plus | 复用登录鉴权、菜单权限、操作日志等基础能力 |

## 二、逻辑实现（分）

### 2.1 目录结构

```
plus-ui/src/views/goodfish/
├── dashboard/           # 仪表盘
│   └── index.vue
├── account/             # 账号管理
│   └── index.vue
├── item/                # 商品管理（含提示词编辑）
│   └── index.vue
├── template/            # 提示词模板
│   └── index.vue
├── provider/            # 模型供应商
│   └── index.vue
├── model/               # 模型管理
│   └── index.vue
└── version/             # 版本管理
    └── index.vue
```

### 2.2 菜单结构

```
闲鱼管理
├── 仪表盘
├── 账号管理
├── 商品管理
├── 提示词模板（只读）
├── 模型管理
└── 版本管理
```

> **提示词模板页面为只读**：数据来自商品服务的 Spring 配置文件（`goodfish-prompt-templates.yml`），仅支持「查看」与「导入到商品」，**不提供新增 / 编辑 / 删除**。

### 2.3 接口前缀与归属（前端需知）

前端调用的接口按 §3.5 裁定分两类：

| 页面 | 接口前缀 | 归属 |
|---|---|---|
| 仪表盘 | `/goodfish/admin/dashboard/**` | **admin BFF**（跨域聚合） |
| 商品管理·列表 | `/goodfish/admin/item/list` | **admin BFF**（跨域聚合） |
| 商品管理·编辑/删除/复制提示词 | `/goodfish/item/**` | 直连商品服务 |
| 提示词模板 | `/goodfish/item/template/**` | 直连商品服务 |
| 账号管理·列表/详情/备注 | `/goodfish/meta/account/**` | 直连客户端元数据服务 |
| 账号管理·删除 | `/goodfish/admin/account/{id}` | **admin BFF**（聚合：商品数校验 + 删除账号） |
| 版本管理 | `/goodfish/meta/version/**` | 直连客户端元数据服务 |
| 模型管理 | `/goodfish/llm/**` | 直连模型服务 |

**与旧版相比的前缀变化（前端需同步调整）**：

> - 模型管理：`/goodfish/provider/**`、`/goodfish/model/**` → **`/goodfish/llm/**`**
> - 账号管理：`/goodfish/account/**` → **`/goodfish/meta/account/**`**
> - 版本管理：`/goodfish/version/**` → **`/goodfish/meta/version/**`**
> - 提示词模板：`/goodfish/template/**` → **`/goodfish/item/template/**`**
