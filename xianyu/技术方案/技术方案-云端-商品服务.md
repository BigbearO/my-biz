## 一、功能与职责（总）

### 1.1 功能定位

商品服务 `goodfish-item-service` 是基础微服务，负责闲鱼商品的同步落库、商品查询与提示词配置管理，并向对话服务提供「商品 + 提示词」运行时配置查询。

### 1.2 职责边界

| 负责 | 不负责 |
|---|---|
| ① 商品同步落库（客户端上报，upsert） | 不渲染提示词 |
| ② 商品查询 | 不调用大模型 |
| ③ 提示词配置 CRUD（**与商品一对一直接关联**） | 不感知对话 |
| ④ 提供**商品 + 提示词运行时配置**（供对话服务 gRPC 查询） | 提示词模板不建表、不提供模板增删改（见 2.3） |

### 1.3 与其他模块的关系

| 对象 | 方向 | 协议/说明 |
|---|---|---|
| 对话服务 `goodfish-ai-service` | 被其调用 | gRPC：`GetItemRuntimeConfig` / `BatchGetItemRuntimeConfig`（见 [技术方案-云端-gRPC契约](技术方案-云端-gRPC契约.md)） |
| 客户端 | 被其调用 | REST：`/goodfish/item/client/sync`（客户端同步，经网关转发） |
| 管理后台（plus-ui） | 被其调用 | REST：`/goodfish/item/**`（单域 CRUD 直连） |
| 客户端元数据服务 | 调用 | gRPC：`GetAccountByGoodfishId`（同步时将闲鱼账号 ID 解析为 `account_id`，见 [技术方案-云端-客户端元数据服务](技术方案-云端-客户端元数据服务.md)） |
| 运行时配置缓存（**Redis**） | 自持有 | 查询结果缓存（**共享 Redis**）：**TTL 60s 兜底 + 编辑/同步变更时主动删除**（任意实例删除即全局生效，见 2.4） |

## 二、逻辑实现（分）

### 2.1 总体设计

- 商品与提示词配置**一对一**：提示词配置独立成表 `goodfish_item_prompt`，与 `goodfish_item` 一对一直接关联（见「三、数据设计」）。
- 对话服务获取运行时配置**不直连本服务的库、不拉取整表**，只按 `(account_id, item_id)` 单条查询（边界详见 2.4）。
- **缓存由本服务（提供方）负责，调用方无感**：缓存介质为 **Redis（共享缓存）**，TTL 60s 兜底 + 变更时主动删除缓存，对话服务每次直接 gRPC 获取（详见 2.4）。

### 2.2 同步逻辑（关键逻辑）

- 同步**只增不删**（A11）；
- 已存在商品**保留提示词配置**；
- **账号解析失败即中止同步（已裁定）**：同步入口先经 gRPC `GetAccountByGoodfishId` 将上报的 `goodfish_account_id` 解析为云端 `account_id`；解析失败（**该账号未上报或上报失败，云端无此账号**）→ **直接抛出异常，同步整体失败，不继续运行**——不做部分落库，事务回滚；客户端收到错误后提示用户，先完成账号上报（重新添加账号触发上报）再重新同步；
- 商品或提示词发生变更时，**主动删除本服务对应的运行时配置缓存**（TTL 兜底）。

### 2.3 提示词模板（Spring 配置内置，不建表）

内置模板放在**商品服务的 Spring 配置文件**（如 `goodfish-prompt-templates.yml`），应用启动时加载为**只读**常量：

```yaml
# goodfish-item-service: src/main/resources/goodfish-prompt-templates.yml
goodfish:
  prompt-templates:
    - code: default_kefu
      name: 通用客服
      content: |
        你是一位专业的闲鱼客服AI助手。请根据用户消息和上下文，直接生成合适的回复。
        ## 商品信息
        标题：{{item_title}}
        描述：{{item_desc}}
        价格：{{item_price}}
        ## 核心原则
        ……
        ## 买家问题
        基于上述，回复买家。问题如下：
        {{question}}
    - code: price_bargain
      name: 议价场景
      content: |
        （议价场景提示词……）
```

| 项 | 说明 |
|---|---|
| **用途** | 仅用于后台「从模板导入」填充到商品的 `goodfish_item_prompt`；**运行时链路不读取** |
| **可编辑性** | **只读**：调整模板需改配置文件后重新发布 |
| **为什么不建表** | 模板是**系统内置的少量固定内容**，不需要用户在页面上维护；放配置可随版本走、可纳入代码评审 |
| **演进** | 若后续确需「用户自定义模板库」，再新建表并补 CRUD —— **接口不变**，仅数据来源从配置切到表 |

### 2.4 与对话服务的数据边界与缓存策略（明确）

- 对话服务**不直连本服务的库**，也不拉取整表；只通过 `ItemService.GetItemRuntimeConfig` 按 `(account_id, item_id)` 取**单条**运行时配置
- **缓存策略——提供方负责，调用方无感**：
  - 对话服务**不做任何缓存、不做失效订阅**，每次对话直接经 gRPC 获取
  - 本服务在提供方侧缓存查询结果，**缓存介质为 Redis（共享缓存，非进程内本地缓存）**：**编辑/同步变更时主动删除缓存 + TTL 60s 兜底**（多实例共用同一 Redis，任意实例删除即全局生效；TTL 仅作兜底）
  - **不使用 Nacos 版本键**（原 `goodfish.item.revision` 方案已废除）；proto 中的 `item_version` / `prompt_version` 字段已随之移除
- 商品被删除后，`GetItemRuntimeConfig` 返回 `NOT_FOUND` → 对话服务返回 40401，客户端不回复

## 三、数据设计

### 3.1 表：`goodfish_item`（商品表）

| 字段 | 类型（PG） | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键，自增 |
| account_id | BIGINT | 关联 `goodfish_account.id`（业务主键，同步时经 gRPC `GetAccountByGoodfishId` 解析） |
| goodfish_account_id | VARCHAR(64) | 冗余字段：闲鱼账号 ID——**对话链路按此字段直查**（`GetItemRuntimeConfig.account_id` 即闲鱼 ID），不做跨服务解析 |
| goodfish_item_id | VARCHAR(64) | 闲鱼商品 ID |
| title | VARCHAR(256) | 商品标题 |
| description | TEXT | 商品描述 |
| price | NUMERIC(10,2) | 价格 |
| stock_status | VARCHAR(32) | 库存状态 |
| image_url | VARCHAR(500) | 商品主图（**本期不同步，字段保留、暂不写入**） |
| sync_time | TIMESTAMP | 最后同步时间 |
| create_dept / create_by / create_time / update_by / update_time | — | RuoYi 自带字段（`*_time` 均为 `TIMESTAMP`） |

**索引**：`uk_gfid_item(goodfish_account_id, goodfish_item_id)` 联合唯一索引（以闲鱼 ID 冗余字段为准）；`account_id` 保留普通索引供后台按账号聚合

> **冗余字段一致性**：`goodfish_account_id` 与账号表 `goodfish_account.goodfish_id` 同源（客户端上报），账号昵称变更不影响该 ID；后台改名等操作不触碰此字段，无同步负担。

### 3.2 表：`goodfish_item_prompt`（商品提示词配置）

| 字段 | 类型（PG） | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键，自增 |
| item_id | BIGINT | 关联 `goodfish_item.id`，**唯一索引**（一对一） |
| system_prompt | TEXT | 系统提示词（人设 + 核心原则） |
| price_prompt | TEXT | 议价场景提示词 |
| tech_prompt | TEXT | 技术场景提示词 |
| default_prompt | TEXT | 默认场景提示词 |
| max_reply_length | INTEGER | 最大回复字数，默认 50 |
| temperature | NUMERIC(3,2) | 温度，默认 0.70 |
| max_tokens | INTEGER | 最大输出 token，默认 2048 |
| create_dept / create_by / create_time / update_by / update_time | — | RuoYi 自带字段 |

> 缓存相关版本字段（`goodfish_item.version`、`goodfish_item_prompt.prompt_version`）**已移除**：缓存失效统一由提供方「Redis 缓存 + TTL + 编辑时删除」承担，无需版本号参与（见 2.4）。

> **本期提示词范围**：页面只编辑 `system_prompt` + 高级设置（`max_reply_length` / `temperature` / `max_tokens`）；`price_prompt` / `tech_prompt` / `default_prompt` **字段保留但留空**，待后续迭代（见《需求-云端-商品管理》第六节）。

## 四、接口设计

### 4.1 gRPC（供对话服务查询）

| 方法 | 说明 |
|---|---|
| `ItemService.GetItemRuntimeConfig` | 按 `(account_id, item_id)` 取**单条**「商品 + 提示词」运行时配置 |
| `ItemService.BatchGetItemRuntimeConfig` | 批量查询运行时配置 |

proto 完整定义收录于 [技术方案-云端-gRPC契约](技术方案-云端-gRPC契约.md)，此处不重复复制。

### 4.2 REST（北向）

`/goodfish/item/**`（后台 CRUD，单域直连）、`/goodfish/item/client/sync`（客户端同步，经网关转发）。

管理后台直连本服务的接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/goodfish/item/{id}` | GET | 商品详情（含提示词配置） |
| `/goodfish/item` | PUT | 更新商品 + `goodfish_item_prompt` |
| `/goodfish/item/{id}` | DELETE | 删除商品 |
| `/goodfish/item/copy-prompt` | POST | 复制提示词到其他商品（复制后独立可编辑） |
| `/goodfish/item/template/list` | GET | 提示词模板列表（**只读**，来自 Spring 配置，见 2.3） |
| `/goodfish/item/count` | GET | **按账号统计商品数**（参数 `goodfish_account_id`；供 admin BFF 删除账号前校验"是否仍有商品"，见 [技术方案-云端-管理后台BFF](技术方案-云端-管理后台BFF.md)） |

**同步接口错误码**（`/goodfish/item/client/sync`）：账号未上报 / 云端无此账号 → **`40403`（账号不存在）**，整批拒绝、事务回滚、不做部分落库；客户端提示用户先完成账号上报再重新同步。
