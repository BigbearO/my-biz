# 技术方案-客户端-图片处理

> 来源：[《客户端监听.md》](../客户端监听.md) §2.4 图片处理；[《客户端技术方案.md》](../客户端技术方案.md) §6.3 图片处理器（内容重组收录，原文件保留未动）
> 关联：[需求-客户端-图片消息](../需求/需求-客户端-图片消息.md)

## 一、功能与职责（总）

### 1.1 功能定位

图片服务（`services/image_service.py`，[《客户端技术方案.md》](../客户端技术方案.md) 中称 `image_processor.py`）负责买家发来的图片消息的本地加工：**用闲鱼 Cookie 下载闲鱼图片 → 统一转 PNG → 上传后端换取图片 URL**，并把 URL 并入消息批次供云端多模态大模型处理。

**图片走 URL，不出现 base64，不使用 `ruoyi-file`**：客户端负责下载与上传，后端把 PNG 存**服务器本地磁盘**并提供访问 URL；`/api/ai/reply` 只带 URL，大模型只收 URL。

### 1.2 职责边界

| 负责 | 不负责 |
|---|---|
| 闲鱼图片下载（带闲鱼 Cookie、超时与重试） | 图片文件的云端长期存储策略（后端存服务器本地磁盘并提供 URL） |
| 统一转 PNG（内存 / 临时文件中转，本机不长期留存） | 消息批次组装与窗口合并（流水线，见 [技术方案-客户端-消息处理流水线](技术方案-客户端-消息处理流水线.md)） |
| 上传后端 `POST /api/ai/image` 换取 URL（带登录 token） | AI 多模态识别（云端大模型完成） |
| 单批张数约束（超限丢弃并告警）与失败降级占位 | 图片消息的最终回复生成（流水线下游环节） |

### 1.3 与其他模块的关系

| 对象 | 方向 | 交互方式 |
|---|---|---|
| 消息处理流水线 | 上游 | 批内含图片时被调用，上传成功后按 `{"type":"image","url":"<后端URL>"}` 并入合并批次 |
| Cookie 管理 | 上游 | 下载闲鱼图片使用解密后的闲鱼 Cookie |
| 云端文件存储 | 下游 | `POST /api/ai/image` 上传 PNG，后端落服务器本地磁盘并返回 URL（云端侧见 [技术方案-云端-文件存储](技术方案-云端-文件存储.md)） |
| 闲鱼协议层 | 下游 | 闲鱼 CDN 图片链接带时效签名，收到即处理 |

## 二、逻辑实现（分）

### 2.1 总体设计

```
批内含图片（滑动窗口合并产物 images[]）
    ↓
逐张下载（闲鱼 Cookie + 超时重试；CDN 链接带时效签名，收到即处理）
    ↓
统一转 PNG（内存 / 临时文件中转，本机不长期留存）
    ↓
POST /api/ai/image（带登录 token）→ 返回 {"url": "<后端图片URL>"}（批内多张可并发上传）
    ↓
按 {"type":"image","url":"<后端URL>"} 并入合并批次；随 /api/ai/reply 上报时映射为 `image_url` 字段
    （任一步失败 → 该图降级为占位文本 [图片]，仅上报文本部分，不阻断流程；
      ★ 上传返回 401 / 403 属鉴权信号，不降级，走 cloud_client 统一鉴权分支）
```

临时文件落 `%TEMP%/goodfish/img`，启动时清理 24h 前残留。

### 2.2 处理方案

| 功能 | 方案 |
|---|---|
| **下载** | 用闲鱼 Cookie 下载图片（带超时与重试；闲鱼 CDN 链接带时效签名，收到即处理） |
| **转 PNG** | 统一保存为 PNG（内存 / 临时文件中转，本机不长期留存；临时文件落 `%TEMP%/goodfish/img`，启动时清理 24h 前残留） |
| **上传后端** | `POST /api/ai/image`（带登录 token）→ 返回 `{"url": "<后端图片URL>"}`；批内多张图片逐张上传（可并发） |
| **进入流水线** | 上传成功后按 `{"type":"image","url":"<后端URL>"}` 并入合并批次；随 `/api/ai/reply` 上报时映射为 `image_url` 字段 |
| **体积约束** ★ | 单次最多 5 张图片（`max_per_batch`，本地配置项）；超限丢弃多余图片并记 WARN |
| **多模态** | 图文合并一起传给云端，由多模态大模型处理（A36） |
| **降级** ★ | 下载 / 上传失败不阻断流程：该图替换为占位文本 `[图片]`，仅上报文本部分。**★例外：上传返回 401 / 40101 / 403 / 40301 时不降级**，交由 cloud_client 走统一鉴权分支（见 §五） |
| **可配置** | 单次张数上限 / 下载超时走本地配置 |

## 五、异常与容错

| 异常场景 | 处理策略 |
|---|---|
| **图片下载失败** | 该图替换为 `[图片]` 占位，仅上报文本，不阻断流程 |
| **图片上传后端失败** | 同上（客户端上传失败时降级） |
| **图片上传返回 401 / 403** ★ | **不降级**——走 cloud_client 统一鉴权分支：401 / 40101 → 删本地 token + 跳登录页；403 / 40301 → 删 token + 停所有监听 + 冻结应用。仅网络异常 / 5xx / 40001（体积超限）才降级为 `[图片]` |
| **单批图片超限** | 超过 `max_per_batch`（5 张）丢弃多余图片并记 WARN |
| **临时文件残留** | 启动时清理 `%TEMP%/goodfish/img` 中 24h 前残留 |

## 六、配置项

| 配置键 | 默认值 | 说明 |
|---|---|---|
| img_max_count（`max_per_batch`） | 5 | 单次最多图片张数 |
| img_max_total_mb | 10 | 单次图片总体积上限（MB，与云端单张上限 `image.max_size_mb=10` 对齐） |
| 下载超时 | 本地配置 | 闲鱼图片下载超时时间 |
