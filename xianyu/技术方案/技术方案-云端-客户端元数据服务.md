## 一、功能与职责（总）

### 1.1 功能定位

客户端元数据服务 `goodfish-client-meta-service` 是基础微服务，管理闲鱼账号元数据与客户端版本两个领域的数据。

**一个部署单元，两个 gRPC 服务**：契约按领域拆（`AccountService` 账号域、`VersionService` 版本域各自独立 proto 契约），部署按成本合（两个 gRPC 服务合并为一个进程部署）。架构层面的说明见 [技术方案-云端-架构总览](技术方案-云端-架构总览.md)。

### 1.2 职责边界

| 负责 | 不负责 |
|---|---|
| ① 闲鱼账号信息 upsert（客户端上报） | **绝不存储 Cookie**（A10） |
| ② 账号列表/详情查询、备注修改、最后活跃时间维护 | 不做登录鉴权 |
| ③ 客户端版本发布（版本号、更新说明、强升标记、安装包地址与大小） | 不做授权判定（由 `ruoyi-system` 负责，见 [技术方案-云端-鉴权与授权](技术方案-云端-鉴权与授权.md)） |
| ④ 更新检查 | |

### 1.3 与其他模块的关系

| 对象 | 方向 | 协议/说明 |
|---|---|---|
| 客户端 | 被其调用 | gRPC：`AccountService.UpsertAccount`（账号上报）、`VersionService.CheckUpdate`（更新检查）；REST 直连 `/goodfish/meta/**` |
| 管理后台（plus-ui） | 被其调用 | REST 直连：`/goodfish/meta/account/**`、`/goodfish/meta/version/**` |
| 商品服务 | 被其调用 | gRPC：`GetAccountByGoodfishId`（商品同步时解析 `account_id`，见 [技术方案-云端-商品服务](技术方案-云端-商品服务.md)） |
| 文件存储 | 提供 | 安装包存服务器本地磁盘，由本服务提供上传/下载（见 [技术方案-云端-文件存储](技术方案-云端-文件存储.md)） |

## 二、逻辑实现（分）

### 2.1 总体设计

一个部署单元承载账号域与版本域两个 gRPC 服务（契约按领域拆、部署按成本合，见 1.1）；北向 REST 面向管理后台与客户端直连。账号域按 `goodfish_id` 维护账号元数据，版本域按版本号维护客户端发布记录。

### 2.2 账号域关键逻辑

- 账号按 `goodfish_id` upsert（已有则更新昵称/备注/有效性）；
- 最后活跃时间由本服务维护。

### 2.3 版本域关键逻辑

- 强升版本无「以后再说」（A15）；
- 安装包存服务器本地磁盘，由本服务提供上传/下载。

## 三、数据设计

### 3.1 表：`goodfish_account`（闲鱼账号表）

存储本机上报的闲鱼账号信息，**不存储 Cookie**。

| 字段 | 类型（PG） | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键，自增 |
| goodfish_id | VARCHAR(64) | 闲鱼用户 ID，唯一索引 |
| goodfish_nickname | VARCHAR(128) | 闲鱼昵称 |
| remark | VARCHAR(256) | 备注 |
| is_valid | BOOLEAN | 是否有效 |
| last_active_at | TIMESTAMP | 最后活跃时间 |
| create_dept / create_by / create_time / update_by / update_time | — | RuoYi 自带字段 |

### 3.2 表：`client_version`（客户端版本表）

| 字段 | 类型（PG） | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键，自增 |
| version | VARCHAR(32) | 版本号，唯一索引 |
| release_notes | TEXT | 更新说明 |
| force_update | BOOLEAN | 是否强制更新 |
| download_url | VARCHAR(256) | 安装包下载地址 |
| file_size | BIGINT | 安装包大小（字节） |
| create_dept / create_by / create_time / update_by / update_time | — | RuoYi 自带字段 |

## 四、接口设计

### 4.1 gRPC

| 领域 | 服务 | 方法 |
|---|---|---|
| 账号域 | `AccountService` | `UpsertAccount`、`GetAccount`、`GetAccountByGoodfishId`、`ListAccounts` |
| 版本域 | `VersionService` | `CheckUpdate` |

proto 完整定义（`account.proto` / `version.proto`）收录于 [技术方案-云端-gRPC契约](技术方案-云端-gRPC契约.md)，此处不重复复制。

### 4.2 REST（北向，后台 + 客户端直连）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/goodfish/meta/account/list` | GET | 账号列表（分页） |
| `/goodfish/meta/account/{id}` | GET | 账号详情 |
| `/goodfish/meta/account` | PUT | 更新账号备注 |
| `/goodfish/meta/account/{id}` | DELETE | 删除账号 |
| `/goodfish/meta/version/list` | GET | 版本列表 |
| `/goodfish/meta/version` | POST | 发布新版本（安装包上传存服务器本地磁盘，见 [技术方案-云端-文件存储](技术方案-云端-文件存储.md)） |
| `/goodfish/meta/version/force/{id}` | PUT | 设置强制更新 |
| `/goodfish/meta/version/{id}` | DELETE | 删除版本 |
