# 技术方案-云端-文件存储

> 来源：《云端技术方案.md》§十一 文件存储（内容重组收录，原文件保留未动）
> 关联：[技术方案-云端-对话服务-接口与幂等](技术方案-云端-对话服务-接口与幂等.md)、[需求-云端-图片消息](../需求/需求-云端-图片消息.md)

## 一、功能与职责（总）

### 1.1 功能定位

定义闲鱼自动回复系统云端侧所有文件（客户端安装包、商品图片、买家聊天图片）的存储位置、归属服务与访问方式。核心结论：所有文件一律存【服务器本地磁盘】，由**归属服务**自行提供上传与下载接口。

### 1.2 职责边界 / 范围

- **不使用 `ruoyi-file` 模块**：只用 RuoYi 的基础管理功能（登录/鉴权/用户/权限/字典等），文件能力不走 RuoYi 通用文件上传。
- 本版本**不上云存储**（OSS/S3 等均不引入）。
- 文件由**归属服务**自行提供上传与下载接口，不设统一文件服务。

### 1.3 与其他模块的关系

| 相关模块 | 关系 |
|---|---|
| 对话服务（goodfish-ai-service） | 买家聊天图片的归属服务：提供上传接口 `/api/ai/image` 与静态访问接口 `/api/ai/image/{filename}`，存本地磁盘 |
| 客户端元数据服务 | 客户端安装包的归属服务：发布新版本时上传安装包存本地磁盘，`client_version.download_url` 存本服务下载地址 |
| 商品服务 | 商品图片的归属服务：客户端同步时如带图片则存本地磁盘，库中仅存 URL |
| 客户端 | 用闲鱼 Cookie 下载图片 → 转 PNG → 带 token 上传；带 token 下载安装包；下载/上传失败降级为占位文本 |
| 网关 | 图片静态访问接口加入免鉴权白名单（`security.ignore.whites`） |
| 大模型厂商 | 通过 `public_base_url` 公网拉取买家聊天图片（多模态输入） |

## 二、逻辑实现（分）

### 2.1 总体设计

存储原则：**不用 RuoYi 的 `ruoyi-file` 模块；所有文件一律存【服务器本地磁盘】，不上云存储**。文件由归属服务自理上传与下载。

三类文件的归属与存储访问方式：

| 文件类型 | 归属服务 | 存储与访问 |
|---|---|---|
| 客户端安装包 | 客户端元数据服务 | 发布新版本时上传至本服务 → 存本地磁盘（如 `/data/goodfish/pkg`）→ `client_version.download_url` 存本服务下载地址；客户端带 token 下载 |
| 商品图片 | 商品服务 | 客户端同步时如带图片 → 商品服务存本地磁盘 → 仅存 URL |
| **买家聊天图片** | **对话服务（goodfish-ai-service）** | 详见 2.2 |

### 2.2 买家聊天图片完整链路

```
客户端用闲鱼 Cookie 下载图片 → 转 PNG → POST /api/ai/image（带 token）上传
    ↓
对话服务存服务器本地磁盘（image.storage_dir，UUID 文件名）→ 返回访问 URL
    ↓
/api/ai/reply 携带 {"type":"image","url":"<对话服务图片URL>"}
    ↓
对大模型传该 URL（OpenAI 多模态格式 {"type":"image_url","image_url":{"url":...}}）
```

链路要点：

- `ai_conversation_message.content` 存该 URL；历史回放复用同一 URL，**不重复上传**。
- 过期清理：`tasks/cleanup.py` 按 `image.retention_hours`（默认 72h）删除过期文件（见 2.4）。
- 客户端下载 / 上传失败降级为占位文本 `[图片]`，不阻断回复流程（见 五）。

### 2.3 静态访问与安全

- **静态访问免鉴权**：`GET /api/ai/image/{filename}` 需加入网关白名单（`security.ignore.whites`）——大模型厂商拉取图片无法携带 token。
- 文件名用 **UUID**，不可枚举；目录不可列举。
- `public_base_url` 指向经网关的公网域名（厂商侧拉取需公网可达）。

### 2.4 过期清理

由 `tasks/cleanup.py` 定期执行：按 `image.retention_hours`（默认 **72h**）扫描 `image.storage_dir`，删除过期图片文件。

## 三、数据设计

| 数据 | 存储 | 说明 |
|---|---|---|
| 买家聊天图片文件 | 服务器本地磁盘 `image.storage_dir`，UUID 文件名 | 原始图片转 PNG 后存储 |
| 图片访问 URL | `ai_conversation_message.content` | 历史回放复用同一 URL，不重复上传 |
| 安装包下载地址 | `client_version.download_url` | 存客户端元数据服务本服务的下载地址 |
| 商品图片 URL | 商品服务库表 | 图片文件存本地磁盘，库中仅存 URL |

## 四、接口设计

买家聊天图片相关接口（完整对话服务接口清单见《技术方案-云端-对话服务-接口与幂等》）：

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/ai/image` | POST | 图片上传：客户端上传 PNG（带 token），对话服务存服务器本地磁盘，返回访问 URL |
| `/api/ai/image/{filename}` | GET | 图片静态访问：**免鉴权**（网关白名单），供大模型厂商拉取；UUID 文件名 |
| `/api/ai/reply` | POST | 生成 AI 回复：请求携带 `{"type":"image","url":"<图片URL>"}`，对话服务将该 URL 以 OpenAI 多模态格式传给大模型 |

## 五、异常与容错

- **客户端下载 / 上传失败**：降级为占位文本 `[图片]`，不阻断回复流程。
- 对话服务自身（含图片上传接口）的异常处理与降级策略见《[技术方案-云端-异常与容错](技术方案-云端-异常与容错.md)》。

## 六、配置项

| 配置键 | 说明 |
|---|---|
| `image.storage_dir` | 对话服务图片存储目录（服务器本地磁盘） |
| `image.retention_hours` | 图片保留时长，默认 **72h**，过期由 `tasks/cleanup.py` 清理 |
| `public_base_url` | 经网关的公网域名，用于拼接图片访问 URL（厂商侧拉取需公网可达） |
| 网关 `security.ignore.whites` | 白名单需加入 `/api/ai/image/{filename}`（静态访问免鉴权） |

> 客户端侧图片下载/转换/上传的详细设计见《[客户端监听.md](../客户端监听.md)》§2.4、§3.8.1、§3.9 第 9 步与 §3.5.1 `image` 配置。
