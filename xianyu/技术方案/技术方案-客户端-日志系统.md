# 技术方案-客户端-日志系统

> 来源：[《客户端监听.md》](../客户端监听.md) §2.7 日志系统；[《客户端技术方案.md》](../客户端技术方案.md) §5.4 日志接口（内容重组收录，原文件保留未动）
> 关联：[需求-客户端-日志](../需求/需求-客户端-日志.md)

## 一、功能与职责（总）

### 1.1 功能定位

LogManager（`core/logging.py`，loguru）负责客户端运行日志的记录、轮转与查询支撑：记录**系统运行日志 + 消息收发记录（买家消息、AI 回复、发送结果）**，供 Electron 日志页查看、筛选、清空、导出（A13/A34）。

### 1.2 职责边界

| 负责 | 不负责 |
|---|---|
| loguru 轮转配置（10MB × 5 个，zip 压缩）与落盘（`%APPDATA%/goodfish/logs/`） | 消息收发记录的结构化存储（`message_log` 表，见 [技术方案-客户端-本地存储与配置](技术方案-客户端-本地存储与配置.md)） |
| 日志级别控制（DEBUG/INFO/WARNING/ERROR，可配置） | 日志上报云端（不上报；发送失败 3 次仅记本地日志，A19） |
| 日志异步写入（`enqueue=True` 不阻塞事件循环） | Electron 日志页 UI（渲染层实现） |
| 后台日志清理任务（TaskGroup 托管） | 明文敏感信息记录（日志一律不得包含明文 Cookie，见 [技术方案-客户端-Cookie管理与加密](技术方案-客户端-Cookie管理与加密.md)） |

### 1.3 与其他模块的关系

| 对象 | 方向 | 交互方式 |
|---|---|---|
| 全部业务模块 | 上游 | 各模块经 loguru 写日志（消息收发、AI 请求/响应、错误异常，A34） |
| Electron 日志页 | 下游 | 经 `/api/logs/*` 本地接口读取、清空、导出 |
| 本地 API（logs/list） | 下游 | 日志经 `/api/logs/list` 供渲染层轮询获取 |
| 进程管理 | 下游 | 退出时 flush 日志后关闭（优雅关闭步骤 4） |

## 二、逻辑实现（分）

### 2.1 总体设计

| 功能 | 方案 |
|---|---|
| **日志内容** | 系统运行日志 + 消息收发记录（买家消息、AI 回复、发送结果） |
| **轮转策略** | 单文件 10MB，最多保留 5 个，超限删除最旧（A24） |
| **日志级别** | DEBUG/INFO/WARNING/ERROR，可配置 |
| **查看方式** | Electron 日志页读取日志文件，支持按级别筛选、清空、导出（A13/A34） |
| **实现** ★ | loguru：`rotation="10 MB"`、`retention=5`、`compression="zip"`、`enqueue=True`（异步写不阻塞事件循环） |
| **落盘位置** ★ | `%APPDATA%/goodfish/logs/`，打包后目录可写（禁止写 exe 同级目录） |

## 四、接口设计

基础地址：`http://127.0.0.1:{port}/api`（端口协商与 `X-Local-Token` 见 [技术方案-客户端-本地API](技术方案-客户端-本地API.md)）。

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/logs/list | GET | 日志列表（分页、按级别筛选） |
| /api/logs/clear | POST | 清空日志 |
| /api/logs/export | GET | 导出日志 |

监听方案合并表述：`/api/logs/list` / `clear` / `export`（GET/POST/GET）——日志查询、清空、导出。

## 五、异常与容错

| 异常场景 | 处理策略 |
|---|---|
| 写日志阻塞风险 | `enqueue=True` 异步写，不阻塞 asyncio 事件循环（WS 心跳不受影响） |
| 打包后目录不可写 | 落盘固定 `%APPDATA%/goodfish/logs/`，禁止写 exe 同级目录（Program Files 无写权限） |
| 磁盘占用失控 | 单文件 10MB、最多 5 个、zip 压缩，超限删除最旧（A24）；日志清理任务由 TaskGroup 托管，异常记日志并重启该任务 |
| 敏感信息泄露 | 日志、异常栈一律不得包含明文 Cookie（见 [技术方案-客户端-Cookie管理与加密](技术方案-客户端-Cookie管理与加密.md)） |

## 六、配置项

| 配置键 | 默认值 | 说明 |
|---|---|---|
| log_level | INFO | 日志级别（DEBUG/INFO/WARNING/ERROR，可配置，落 SQLite config 表） |
| rotation | 10 MB | 单文件上限（代码常量） |
| retention | 5 | 保留文件数（代码常量） |
| compression | zip | 历史文件压缩方式（代码常量） |
