## 二、文档结构约定

| 约定 | 说明 |
|---|---|
| 命名 | `需求-{客户端\|云端}-{功能点}.md`、`技术方案-{客户端\|云端}-{功能点}.md` |
| 总分结构 | 一/功能（总：功能定位→子功能清单→边界）→ 二+/逻辑实现（分：逐机制展开） |
| 验收标准 | 只出现在需求文档；A 编号**客户端、云端各自独立编号，不要求全局唯一**（客户端 A1–A43、云端 A1–A14；如客户端 A12 与云端 A12 各自存在，各自归属本侧的一个文件） |
| 来源头 | 每文件头部标注「来源：《源文档》§章节（原文件保留未动）」 |
| 交叉链接 | 相对链接：同目录用文件名，跨目录加 `../` |
| 单一事实 | 公共约定（鉴权、错误码、注册契约）只在一个文件写透，他处链接引用 |
